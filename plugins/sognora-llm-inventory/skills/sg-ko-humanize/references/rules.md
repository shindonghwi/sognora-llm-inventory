# sg-ko-humanize — 룰북 (SSOT)

> Claude Code·Codex 양쪽이 공유하는 본체. 내용 수정은 이 파일에서만 한다.
> 패턴 체계는 [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)(MIT)의 quick-rules를 기반으로 간소화·재구성했다.

표기: **[S1]** 결정적(한 번만 나와도 AI 확신 — 무조건 제거) / **[S2]** 강함(반복 시 제거) / **[S3]** 약함(적극 강도에서만).

## Do-NOT (탐지·윤문 모두 제외)

고유명사·제품명·모델명·기관명, 수치·날짜·단위, 큰따옴표 안 직접 인용, 법률 조문, 수학·화학·통계 표기, 표준 technical term과 영어 약어(LLM·GPU·MCP·API·prompt·token 등 — 기계적 직역 금지: prompt→"지시문" ✗).

## 과윤문 가드

변경률 30% 초과 = 경고 고지, 50% 초과 = 채택 금지·롤백. 판정은 자가 산출이 아니라 `scripts/change_rate.py`가 한다(LLM 산수는 부정확하다 — im-not-ai의 핵심 교훈).

## A. 번역투 — S1~S2

- **A-1** [S1] "~에 대해(서)" 남발 → 목적격 조사로 직결("X에 대해 논의" → "X를 논의")
- **A-2** [S2] "~를 통해/통하여" 문단 3회+ → 일부만 "~로", "~해서", "~함으로써"로 분산(1~2회 보존)
- **A-3** [S1] "~에 있어(서)" → "~에서" 또는 "~을 볼 때"
- **A-4** [S2] "~라는 점에서" 3회+ → "~서", "~라는 이유로"
- **A-5** [S2] "~와 관련하여/관련된" → "~에", "~의"
- **A-6** [S2] "~에 기반하여/바탕으로" 남발 → "~로", "~을 보고"
- **A-7** [S1] "가지고 있다", have/make/take/give+명사 직역 → 형용사·동사 환원("강한 경쟁력을 가지고 있다" → "경쟁력이 강하다")
- **A-8** [S1] 이중 피동 "~되어진다/~지게 된다" → 능동 또는 단일 피동("판단되어진다" → "판단된다")
- **A-9** [S2] "~에 의해" 피동 → 행위자를 주어로("AI에 의해 생성" → "AI가 만든")
- **A-10** [S2] "~할 수 있다" 남발 → 단언으로("높일 수 있다" → "높인다")
- **A-11** [S2] "~을 위해" 목적절 남발 → "~려고", "~도록", "~위한"
- **A-15** [S2] 추상 주어 + 만능 동사(보여준다/제공한다/가져온다) → 구체 주어로 환원. 인지 동사(suggest/show) 직역은 "~에 따르면 ~이다"
- **A-16** [S1] "그/그녀/그것/그들" 단락 3회+ (영어 대명사 직역) → 50% 이상 생략하거나 호칭·명사구로
- **A-18** [S2] 명사 앞 3어절+ 관형구 좌향 수식 → 문장 분리 또는 후치 동격절("X를 만났는데, 그 X는 ~")
- **A-19** [S2] 이중 조사 "~에서의/~에로의/~으로의/~에의" → 절·구로 풀어쓰기 (단순 "~의"는 비대상)

## B. 영어 병기·용어 과다 — S2

- **B-1** [S2] 한글 + 괄호 영어 병기 매번 반복 → 첫 등장만 병기, 이후 한글만
- **B-2** [S2] 광고성 buzzword(seamless·robust·leverage) → 한국어로 풀되, 표준 technical term은 원어 보존

## C. 구조적 AI 패턴 — S1~S2

- **C-2** [S2] 칼럼·리포트에서 3개+ 연속 불릿 블록 → 문단 산문으로 통합
- **C-5** [S1] 이모지 남발(리스트 머리·헤딩·강조) → 칼럼·리포트 장르면 전부 삭제
- **C-7** [S2] 문단 문두 "먼저-반면-결국" 3단 공식 → 접속사 1~2개로 줄이거나 본문에 녹임
- **C-8** [S2] "A인가, B인가"·"A가 아니라 B" 대구 3회+ → 한 번만 살리고 나머지는 직접 단언으로 (전부 깨면 필자 목소리가 죽는다 — 1회는 보존)
- **C-9** [S2] 숫자 괄호 인덱싱 "1) 2) 3)" → 본문에 녹이거나 "우선~", "다음으로~"로 변주
- **C-10** [S1] 콜론 부제 헤딩 "X: Y" 반복 → 단일 명사구로 압축 (학술·보고서의 실제 절 제목은 보존)
- **C-11** [S1] 연결어미(-고/-며/-지만/-면서/-아서) 직후 쉼표 → 쉼표 제거. 6회+ = 강한 신호 (한국어 최강 단일 분리 신호)

## D. AI 특유 관용구 — S1

- **D-1** [S1] 결산 lexicon "결론적으로/이를 통해/요약하면/정리하자면" 3회+ → 1~2건만 남기고 삭제
- **D-2** [S1] "시사하는 바가 크다/주목할 만하다/매우 중요하다" 의의 과장 → 삭제 또는 구체 결론으로
- **D-3** [S1] 열거 도입 "크게 세 가지로 나눌 수 있다/다음과 같은" → 도입구 삭제, 바로 본론
- **D-4** [S1] hype 어휘(혁신적/획기적/압도적/파격적/전례 없는) 3회+ → 구체 수치·사실로 환원
- **D-5** [S1] 의인화 추상 주어("기술이 묻는다", "시대가 부른다") → 사람·기관 주어로
- **D-6** [S1] 결말 공식 "~할 때입니다/~시점입니다" → 구체 동사 단언, 문서당 1회 이하
- **D-7** [S1] 변환 공식 "X에서 Y로/X을 넘어 Y로" 반복 → 직접 단언, 문서당 1회 이하

## E. 리듬 균일성 — S2

- **E-1** [S2] 문장 길이 균일 + 장문 부재 → 단문 1~2개 + 인접 문장을 이은 장문 1개를 문단마다 (내용 추가 금지)
- **E-2** [S2] 동일 종결어미 4문장+ 연속, "~고 있다" 자동 진행형 → 종결 다양화, 단순 시제로 환원("읽고 있다" → "읽는다")
- **E-7** [S2] 청자 경어법(해라/해요/합쇼) 한 문서 내 혼재(대화·구어 한정) → 하나로 일관

## F. 과도한 수식·중복 — S2

- **F-4** [S2] 한자어 명사화 -성/-적/-화 + 영어 -tion/-ment 직역 누적 → 동사·형용사 어근으로("정책의 시행" → "정책 시행")
- **F-5** [S2] "~적 N" 추상 체인("전략적 함의") 3회+ → 명사+명사 또는 풀어쓰기("전략 함의")

## G. Hedging 남용 — S2

- **G-1** [S2] "~로 보인다/~로 판단된다/~인 듯하다" 남발 → 단언 가능한 곳은 단언
- **G-2** [S2] 이중·삼중 완곡 "~할 가능성이 있을 수 있다" → 완곡 하나만
- **G-3** [S2] 균형 lexicon "양쪽 모두/장점도 있지만/신중하게" 4회+ → 한쪽 단언·구체 비교로

## H. 접속사 남발 — S2

- **H-1** [S1] 문두 "또한/따라서/즉/나아가/아울러" 5회+ → 대량 제거, 문장이 흐름을 잡게
- **H-3** [S2] 메타 진입 "이는 ~/이 점에서/이 말은" 3회+ → 본문에 녹이거나 삭제
- **H-4** [S2] "즉" 남발 → 변주 또는 생략, 문서당 2회 이하

## I. 형식명사 과다 — S2

- **I-1** [S1] "~한 것이다/~일 것이다" 연속 3회+ → 일부만 "~다"로 (기본 보존)
- **I-2** [S2] "주목할 점은 ~라는 점이다" 형식명사 강조 → "X는 ~다" 직설로
- **I-3** [S2] "~다는 것이다/~다는 뜻이다" 결말 → "~다" 직접 종결, 합산 2회 이하
- **I-4** [S2] 권고형 결말 "~해야 한다/~할 필요가 있다" 5회+ → 주체 명시 단언·조건문으로 변주

## J. 시각 장식 남용 — S2~S3

- **J-1** [S2] 문장마다 핵심 단어 ** 볼드 → 칼럼·리포트면 본문 볼드 거의 제거
- **J-2** [S1] 따옴표 강조 5회+ → 진짜 인용만 남기고 평어로
- **J-3** [S3] 대시(—) 부가 설명 문장마다 반복 → 쉼표·괄호·별도 문장으로 (원문에 이미 있던 대시는 보존)

## 자체검증 체크리스트 (윤문 직후 자가 점검 — 위반 시 해당 edit 롤백)

1. [ ] **보존**: 고유명사·수치·날짜·인용이 원문과 한 글자도 다르지 않은가
2. [ ] **변경률**: 30% 이하인가 (확정 수치는 change_rate.py — 자가 산출은 참고용)
3. [ ] **장르**: 칼럼이 에세이·문학으로, 리포트가 블로그체로 변하지 않았는가
4. [ ] **register 양방향**: 격식체→격식체, 구어→구어. 평어로 떨어뜨리지도 '-하였-'로 올리지도 않았는가
5. [ ] **S1 잔존 0건**: D-1~D-7, A-1, A-3, A-7, A-8, A-16, C-5, C-10, C-11, H-1, I-1, J-2가 남아있지 않은가
6. [ ] **빼기 전용**: 원문에 없던 비유·수사·상투구를 새로 심지 않았는가. 살아있는 구어(감탄·반문·부가설명 대시)는 보존했는가
