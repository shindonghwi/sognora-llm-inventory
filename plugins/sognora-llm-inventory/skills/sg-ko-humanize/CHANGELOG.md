# sg-ko-humanize — CHANGELOG

## 1.6.3 — 2026-08-19 (내용 불변 게이트 신설 — "부정 반전이 통과하던" 사고)

감사 실측: **"환불이 불가능합니다"→"가능합니다", "책임지지 않습니다"→"책임집니다"가 4.1% "OK 수렴"으로 통과**했다. 유일한 게이트인 `change_rate.py`가 `SequenceMatcher` 비율 하나만 재서 **무엇이 바뀌었는지는 전혀 몰랐다.** 폴더 전체 무인 완주가 기본이고 git 폴더면 백업도 안 만드는 스킬에서, 정책·약관 파일이 사정권에 있었다.

- **불변식 축 신설** — 숫자(단위 1어절 결합: 7일→7주·3만→3억 차단)·조항(제N조)·부정·극성·조건 표지·URL·영문 고유명사를 대조. **불변식 위반은 변경률과 무관하게 즉시 중단**이 하드 라인이다.
- **문장·절 쌍 단위 비교** — 파일 전체 총량만 세면 재배치·상쇄가 통과한다(실측: 작용 대상 교환, 숫자 자리 교환, 한쪽 부정 삭제를 다른 쪽 "아니라"로 메꾸기). 짝을 지어 짝 안에서만 대조한다.
- **유사도 기반 재짝짓기** — 정확 일치 정렬은 양쪽으로 터졌다: 문장 하나를 추가해 개수를 어긋내면 공격이 부활하고(통짜 블록 비교), 순수 재배열은 오탐이 났다. **네 결함의 뿌리가 하나**였고 `ratio ≥ 0.6` 그리디 재짝으로 넷이 함께 닫혔다. 헌법 실측: 제자리 윤문 191건 → 오탐 0, 거기에 줄 교환 2곳 추가 → 이전 ABORT(위반 4)에서 **통과**로.
- **부정 판정 정교화** — `(?<!잘)못`(잘못하면 오탐), `안(?=\s?(되|됩|돼|된))`(맞춤법 교정 오탐 + "안 됩니다" 미검출 버그), `아니(?!라)`(룰북이 평서문화를 지시하는 수사 구문), 굳어진 부사(관계없이·틀림없이) 제외, `마십시오|말 것` 추가(법적 경고문의 표준 금지형이 빠져 있었다).
- **극성은 "소실"이 아니라 "짝 교체"** — 소실만으로 잡으면 "면 **선택**"의 '선택'을 필수↔선택으로 오인한다(실측). X가 줄고 반대말 Y가 늘 때만 위반. `"-지 않"` 프레임쌍(적지 않↔많지 않) 포함.
- **짧은 텍스트는 변경률 대신 2-gram 유지율, 그것도 WARN까지** — 하드 라인은 내용이고 분량은 사람이 본다. 한 줄 카피의 정당한 교정이 막히던 문제 해소.
- **`scripts/detect_ko.py` 신설** — 🔴 패턴 16종 정규식 판정, 장르 면제(법률·스펙), 밀도 임계, 코드펜스·URL·front-matter 마스킹, stdin 지원. forge-rules §5 "🔴 패턴 0"의 판정자가 **양쪽 어디에도 없던** 공백을 닫는다.
- **연결어미 뒤 쉼표 🔴 → 🟡 강등 + 법률 전면 면제** — 1987년 헌법 원문에서 `-고,` 15회·`-며,` 49회 실측. "AI 한국어의 대표 지문"으로 규정하면 헌법이 64곳 위반이 된다.
- **막지 못하는 것을 문서에 명시** — 맨몸 반의어 반전·한글 고유명사 단독 실행·이중부정 해소 오탐. 막는 척하지 않는다.
- **`--mode=code` 신설** — i18n 메시지 파일용. 1급 불변식은 **skeleton 동등성**(문자열 리터럴 본문만 치환한 소스가 byte-동일)이라 키·보간·삼항·주석이 자동 동결되고, 값은 위치로 1:1 대응돼 값 쌍마다 문장 쌍 불변식이 그대로 돈다. 미지원 구문은 판별하지 않고 **"관할 밖 — 수정 금지" exit 2**(지원 못 하는 파일을 조용히 통과시키는 것이 최악의 실패 모드다). 실측: 실제 메시지 파일 6개 전수 무결성 통과·폴백 0건.
- **그런데 메시지 파일을 배치 자동 대상에서 뺐다.** 게이트를 만든 뒤 내린 결론이다 — 게이트가 결정적으로 막는 건 **코드 파손**뿐이고, ⓐ 초단문 UI 카피는 불변식 커버리지가 0으로 수렴하며("저장"→"삭제"도 통과) ⓑ 이 룰북은 산문용이라 버튼 라벨엔 부적합하고 ⓒ en/ko 병렬 쌍 정합은 문자열 단위로는 못 본다. **계측기가 생겼다고 문을 여는 게 아니다** — 자동 수집에서 빼고 명시 지정 경로의 안전장치로만 쓴다. description의 "사이트 전체" 공약도 정직하게 축소.
- 검증: 공격 17종 중 16 차단(유일 통과는 문서화된 미방어 항목) · 정당 편집 13종 중 12 통과 · 헌법 40KB 실문서 3종(191편집·재배열·회귀) 전부 통과.
