# sg-biz-validate — CHANGELOG

## 1.6.3 — 2026-08-19 (예산 질문 제거 — 매 런 되묻던 상시 사실을 프로필로)

사용자 지적: "수익 없이 버틸 수 있는 개월 수와 월 예산" 질문이 매번 나오는데 의미가 없다.

- **확인: B1은 과거 두 번의 런에서 한 번도 답이 기록되지 않았고, 그런데도 판정은 나왔다**(`02_verdict.md`가 CAC $3/$6·회수 3.8/7.7개월을 에이전트 계산으로 산출). 판정에 안 쓰이면서 매번 묻고 있었다.
- **B1 삭제.** 서버비·AI 생성 단가·외부 API 요금은 **공개 가격표로 조사되는 값**이라 철칙 1(조사로 알 수 있는 건 묻지 않는다)의 대상이었다. 사용자에게 월 예산을 되묻는 것은 에이전트가 할 계산을 떠넘기는 것이다.
- **§계산 규칙에 "월 고정비 산출" 신설** — 스택에서 항목별로 쌓고(호스팅·DB·스토리지 / AI 추론 단가×건수 / 외부 API / 결제 수수료) 항목마다 출처 URL 또는 "가정" 표시. **변동비(고객 수에 비례하는 AI 생성비)를 고정비에 넣지 말 것** — 손익분기가 실제보다 좋게 나온다.
- **판정 기준 재작성** — "사용자의 자본·기간 안에서 현실적" → "**산출된** 월 고정비·손익분기 고객 수가 시장 규모·확보 채널로 도달 가능한가". 자기보고 입력이 아니라 계산 출력으로 판정한다.
- **`_biz/profile.md`(운영자 프로필) 신설** — 형태·강점·목표 수준·**병렬 한도**(솔로의 진짜 제약은 현금이 아니라 본인 시간)·접는 선. 한 번 만들고 이후 런에서 재사용, 있으면 B군 질문을 통째로 건너뛴다. **금액·기간은 적지 않는다**(시점마다 달라져 금방 낡는다).
- **철칙 2 신설**: "같은 걸 두 번 묻지 않는다 — 매 런 다시 묻는 질문은 그 자체가 결함이다." 자체검증에 항목 3개 추가.
