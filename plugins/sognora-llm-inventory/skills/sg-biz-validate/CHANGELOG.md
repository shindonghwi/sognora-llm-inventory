# sg-biz-validate — CHANGELOG

## 0.1.0 — 2026-08-15

- 최초 생성. 인터뷰(에이전트 리딩) → 경쟁사 발굴·분석 → 진입 판정 → PRD.
- 질문 수는 아이디어 구체성으로 산정 후 사용자에게 예고(최대 8개).
- 경쟁사 인지도 기준 5개 중 2개 이상 + 대체재 1곳 이상 포함, 8축 분석.
- 판정은 진입/조건부/철회 셋 중 하나로 강제, 흐린 표현 금지.

## 0.1.1 — 2026-08-15

- 인자 없이 호출한 경우를 명시: 종료하지 않고 "아이디어 한 줄"을 물어 대화로 시작(질문 개수에 미포함). 파일 경로 인자도 지원.
