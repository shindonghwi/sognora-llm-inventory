## 표본 교차 결론 (2026-08, 19종)

1. **호버에 transform·그림자를 거의 안 쓴다** — 색 전환·옅은 알파 필·brightness가 전부 (toss·linear·stripe·jobber 실측)
2. **duration은 1~2개 값으로 수렴** (linear 0.1/0.16 · toss 0.1/0.2 · jobber 0.25 단일 토큰) · `transition: all` 0개가 상급의 표식
3. **모션의 격은 양이 아니라 어휘 제한** — framer는 최다 모션인데 어휘가 opacity·filter 둘, 커브는 전부 임계감쇠
4. 폰트 단 수보다 **"한 화면 동시 위계 ≤6단"**이 실제 규칙 (toss 18단 실측)
5. **한글 조판 3원칙**: keep-all 전역 · 자간 0 · 행간 역할 결합(본문 1.5~1.6/디스플레이 1.3~1.4) — 어기면 "번역된 템플릿"이 된다 (toss 준수 vs omneky 붕괴 대조)
6. **신뢰의 단위는 장르마다 다르다** — B2B 현장직은 사람 얼굴+앱스토어 별점(jobber), 핀테크는 코드·수치(stripe), 기관은 격·수상(mayo), 소비자는 실물 밀도(airbnb·ohou)
7. **움직임의 값어치는 입력 반응이 아니라 "제품이 일하는 장면"** — aside는 동영상 0·`mousemove` 리스너 0인데도 살아 있다(라이브 DOM 목업 + 자가 렌더 캔버스 + 0.15s 단일 호버). 마우스 추적 효과는 상급 표본에서 0건
8. **브랜드 물성을 CSS로** — 업의 재료(테이프·종이·페인트)를 변수명·마스크·블렌드로 페이지에 스며들게 한 사례(jobber)가 가장 값싼 차별화
