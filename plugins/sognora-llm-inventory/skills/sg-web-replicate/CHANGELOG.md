# sg-web-replicate — CHANGELOG

## 1.6.3 — 2026-08-19 (게이트가 실제로 판정하게 — 감사에서 드러난 치명 결함 대응)

감사 실측: **pixelmatch 없이 도는 "수치 게이트"가 빈 페이지·다크 반전·전 텍스트 굵게·문구 전면 교체를 전부 exit 0으로 통과**시켰다. 그리고 지시받은 환경(nolpop)이 실제로 pixelmatch 미설치 상태였다 — 가정이 아니라 운영 상태였다. "눈대중 금지, 판정은 수치와 diff만"이 SKILL.md의 한 문장으로 무너져 있었다.

- **픽셀 미설치 = 판정 거부(exit 2)**, `--no-pixel` 명시 런은 **exit 3(판정 보류)**. "A급 불가"가 문장뿐이고 exit 0이라 goal("전 라우트 exit 0")이 `--no-pixel`로 달성되던 구멍 — 문장이 아니라 종료 코드가 막는다.
- **폰트 비교 수정**: `font.split(" ")[0]`이 **첫 단어만** 봐서 "Arial Black"↔"Arial Narrow", **"Noto Sans KR"↔"Noto Serif KR"**이 통과했다. family 전체·weight 독립 비교(400→700이 통과하던 것)·line-height(`normal` vs px를 스킵하던 가드) 추가.
- **구조델타를 게이트에 편입** — 요소 수 차이. 빈 페이지가 통과하던 근본 원인(비교 쌍 n=0)이 여기였다.
- **밴드 사각지대 해소**: 스크롤 지점을 `ceil(pageHeight/VH)`로 자동 증설(상한 12), `pixelCoveragePct`를 capture·diff 양쪽 필수 필드로. aside 7492px → 3지점 36% → **9지점 100%**, 비용 +1.1s(+18%). 밴드 사각지대에 섹션을 갈아끼우던 우회가 **PASS(0.82%) → FAIL(99.72%)**.
- **장식 수치 게이트 신설**(색·radius·shadow) — 색은 **캔버스 1px 래스터화로 RGBA 정규화**(lab·oklch 원본과 sRGB 재선언 복제가 같다고 판정). `--no-pixel` 런의 최소 방어선: 색 반전+문구 교체가 **PASS → FAIL(장식 24)**.
- **측정 시점 비대칭 수정** — `comparePng`를 요소 측정 뒤로 이동. PNG 디코드가 수백 ms라 local 측정만 늦어져, 1~3초에 부트하는 위젯이 한쪽에만 잡히며 **동일 URL 자기 비교가 구조델타 -1로 실패**했다(결정적 오탐).
- **측정 불가 영역 규정 + `override.masks` 구현** — 규정만 쓰고 코드가 없으면 "이행 불가 약속"이라 우회 유인을 오히려 키운다(선언까지 했는데 안 되니까). 마스크 zero-out + **면적을 기계가 계산해 기록** + 20% 초과 실패 + **사유 없는 마스크는 exit 2**.
- **가상 시계 동결 채택** — 로드 전 동결 + 고정 예산으로 타이핑·rAF·지연 위젯이 결정화된다(3회 비트 동일 실측). 우려한 부작용(IO 리빌·lazy 이미지·networkidle)은 실측에서 나오지 않았다.
- **콘솔 baseline** — "콘솔 오류 0건" 게이트를 원본 자신이 통과 못 하던 모순(원본 임베드를 그대로 넣으라는 규정과 충돌). 원본 오류를 baseline으로 기록하고 **새 오류만** 센다.
- **자기 대 자기 비교 차단** — ref를 로컬에서 재캡처해 통과시키는 경로. loopback 별칭(localhost↔127.0.0.1)까지 정규화. *초판은 meta.json 경로를 잘못 읽어 죽은 코드였고, 그 상태로 "검증됨"이라 보고됐다 — exit 2가 pixelmatch 거부에서 나온 것을 가드 동작으로 오독한 것이다.*
- **가상 시계 구현** — `install(고정시각)`→`pauseAt`→goto→`runFor(3000)`. capture가 `meta.clock`에 기록하고 diff가 그대로 재현하며, **조건 불일치는 exit 2**(구버전 ref·`--no-clock` 충돌·뷰포트 간 불일치 — 조용히 다른 조건으로 비교하지 않는다). **aside.com 타이핑 히어로가 2회 캡처에서 픽셀 불일치 0.000%** — 이 감사를 시작하게 한 "매 캡처마다 다른 문자열"이 masks 없이 동결됐다. 비용 +8%.
- **마스크 좌표를 문서 좌표로** — 스크롤 지점을 3→9개로 늘린 뒤 뷰포트 좌표 마스크는 의도 밖 영역을 가린다(제 변경이 만든 부채). 창마다 환산해 걸치는 부분만 가리고, sticky/fixed만 `space:"viewport"`.
- **렌더 폰트 홀 차단** — 구현 중 **`document.fonts.check()`가 미지 family에 true를 반환**하는 것을 실측 발견(스펙 특성). 잡으려던 케이스("선언만 있고 @font-face 정의 없음")를 정확히 못 잡아 첫 구현이 조용히 통과했다. 캔버스 `measureText` **이중 폴백 대조**로 교체 — @font-face 한 줄만 지운 복제가 FAIL한다.
- 콘솔 baseline을 **뷰포트 간 합집합**으로(모바일에서만 나는 오류 누락 방지).
- **보류 1건(정직 고지)**: 창 안 2% 예산의 완치법(연결 성분 크기 임계)은 구조 작업이고 정직한 사용에서 터지는 빈도가 낮아 미루었다 — 1440×120 난수 블록조차 0.09%로 통과한다는 실측이 예산의 크기를 보여준다.
- 잔여 한계(정직 고지): 렌더 폰트 홀(선언 family 동일·폴백 상이 — `document.fonts.check()` 필요) · 창 안 2% 예산(CTA 하나 0.86%는 커버리지 100%여도 통과 — 연결 성분 크기 임계가 완치법) · 마스크 좌표가 뷰포트 고정이라 스크롤 지점 증설 후 의도 밖 영역을 가릴 여지.
