# sg-web-replicate — CHANGELOG

## 0.1.0 — 2026-08-14

- 최초 생성. 측정 기반 복제 루프(계약 → 라우트 탐색 → 캡처·측정 → 명세 → 구현 → diff 게이트).
- scripts: discover.mjs(sitemap+크롤, 로그인 벽 탐지) · capture.mjs(브라우저 1회 기동, 뷰포트×상태) · diff.mjs(수치+pixel 게이트).
- daylab.dev로 실측 검증: 라우트 19개 탐색, 자기 비교 PASS, 오류 페이지 FAIL 확인.

## 0.1.1 — 2026-08-15

- 자산 정책을 "원본 그대로"로 전환. fetch-assets.mjs 추가(폰트·이미지·인라인 SVG 원본 수집, @font-face·CSS 변수 추출).
- 폰트 family 불일치를 독립 실패 조건으로 게이트에 추가.
- CORS 차단 스타일시트는 응답 원문에서 @font-face를 파싱(daylab.dev 실측 0건 → 92건).

## 0.1.2 — 2026-08-15

- diff.mjs가 스크롤 지점을 캡처와 같은 숫자순으로 순회하도록 수정(알파벳순 0→100→50이라 스크롤 반응 애니메이션이 다른 상태로 도착, 동일 조건 위반).
- benjaminwestlake.me 전체 복제로 실전 검증: 게이트 전 뷰포트 통과(pixel 0.00%, box 0건).

## 0.1.3 — 2026-08-15

- 기본 라우트 범위를 "주어진 URL 1개" → "탐색된 전부"로 수정. 사이트 복제 요청은 사이트 전체를 뜻한다.
- `--max` 상한에 걸리면 올려서 재탐색하도록 명시(상한은 폭주 방지용이지 작업 범위가 아님).
- 무인 완주 예외에 "범위 확인" 추가 — 고유 페이지 20개 초과 시 임의로 자르지 말고 목록 제시 후 확인.

## 0.1.4 — 2026-08-15

- 라우트 분석 후 별칭 정리 + 그룹별 페이지 수와 함께 선택지로 범위 확인(Claude은 AskUserQuestion).
- goal 모드 연계: 범위 확정 후 Codex는 create_goal(산문 objective), Claude은 ProposeGoal(검증 가능한 술어). 없는 환경은 건너뜀. 완료 판정은 여전히 diff.mjs exit code.

## 0.1.5 — 2026-08-15

- 범위를 "화면(프론트) 전용"으로 명시. 서버 데이터 영역은 같은 모양의 로컬 fixture.
- 캡처와 자산 수집을 동시 실행으로 통합(라우트당 브라우저 왕복 절감).
- 구현 순서를 "대표 페이지 먼저 수렴 → 같은 템플릿 일괄 생성 + 표본 검증"으로 변경.
- 오차 진단 규칙 추가: 같은 값의 오차가 퍼져 있으면 위쪽 높이 차이 하나가 원인. 수치는 맞는데 pixel만 어긋나면 조건 불일치부터 의심.
- 서드파티 임베드 인벤토리 규칙 추가(실측 오차 3건의 원인).
- 옵션의 라우트 기본값 설명이 구버전("주어진 URL 1개")으로 남아 있던 것 수정.

## 0.1.6 — 2026-08-15

- 구현 전 "배치 규칙 확정" 단계 추가: 프로젝트 규칙 문서 → 기존 코드 관례 → 선택지로 확인 순.
- 분리형 구조(라우팅 계층 vs 화면 구현 계층) 준수, 자동 생성 폴더 수정 금지 명시.
- i18n 규칙 추가: 문구 하드코딩 금지, 기본 로케일에만 원문 주입, 나머지는 "번역 필요"로 보고(기계번역 금지).
- 자산은 프로젝트 정적 폴더 관례로 배치(_replica는 산출물 보관소일 뿐).
