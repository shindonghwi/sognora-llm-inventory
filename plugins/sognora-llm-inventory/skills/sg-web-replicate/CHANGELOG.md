## 0.1.0 — 2026-08-14

- 최초 생성. 측정 기반 복제 루프(계약 → 라우트 탐색 → 캡처·측정 → 명세 → 구현 → diff 게이트).

## 0.1.1 — 2026-08-15

- 자산 정책을 "원본 그대로"로 전환. fetch-assets.mjs 추가(폰트·이미지·인라인 SVG 원본 수집, @font-face·CSS 변수 추출).
- 폰트 family 불일치를 독립 실패 조건으로 게이트에 추가.

## 0.1.2 — 2026-08-15

## 0.1.3 — 2026-08-15

- 기본 라우트 범위를 "주어진 URL 1개" → "탐색된 전부"로 수정. 사이트 복제 요청은 사이트 전체를 뜻한다.
- `--max` 상한에 걸리면 올려서 재탐색하도록 명시(상한은 폭주 방지용이지 작업 범위가 아님).
- 무인 완주 예외에 "범위 확인" 추가 — 고유 페이지 20개 초과 시 임의로 자르지 말고 목록 제시 후 확인.

## 0.1.4 — 2026-08-15

- 라우트 분석 후 별칭 정리 + 그룹별 페이지 수와 함께 선택지로 범위 확인(Claude은 AskUserQuestion).
