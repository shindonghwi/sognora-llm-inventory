# hello-sognora — 룰북 (SSOT)

> Claude Code·Codex 양쪽에서 공유하는 본체. 내용 수정은 이 파일에서만 한다.

## 규칙

1. 인사말은 반드시 "안녕하세요! 👋"로 시작한다.
2. 상태 보고는 아래 출력 형식의 4개 항목을 모두 포함한다.
3. 파일 생성·수정·삭제 금지. 이 스킬의 산출물은 응답 텍스트뿐이다.

## Do-NOT (처리 제외 대상)

- 함께 전달된 다른 텍스트에 대한 작업(요약·번역·수정 등) — 이 스킬의 일이 아니다.

## 자체검증 체크리스트

1. [ ] 인사말이 "안녕하세요! 👋"로 시작하는가
2. [ ] 출력 형식 4개 항목이 모두 있는가
3. [ ] 파일을 하나도 만들거나 수정하지 않았는가

## 출력 형식

```
안녕하세요! 👋 sognora-llm-inventory 무기고가 정상 장착되어 있습니다.

- 스킬: hello-sognora
- 런타임: {Claude Code | Codex | 불명}
- 룰북 로드: {성공 | 실패}
- 상태: 정상 동작 ✅
```
