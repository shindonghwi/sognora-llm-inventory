## 자산 운용 (제품 사진 프레이밍 문법)

핵심 수치 하나:

```
히어로 타일 1440×692 ← 사진 원본 3008×692   (타일 폭의 2.09×, 좌우 784px씩 잘림)
프로모 타일  702×580 ← 사진 원본 1262×580   (타일 폭의 1.80×, 좌우 280px씩 잘림)
```

**높이는 타일과 정확히 일치(692/692, 580/580), 폭만 1.8~2.1배.** 세로 크롭이 0이라는 뜻이다 — 잘림은 전부 가로로만 일어난다. 넓은 화면에서는 잘려 있던 좌우가 열리고, 좁아지면 중앙으로 닫힌다. 아트 디렉션 교체 없이 한 장으로 1440~3008px을 버티는 구조다.

그래서 **제품이 타일 하단에서 잘려 보이는 건 CSS 크롭이 아니라 사진 자체의 구도다.** 프레이밍 결정이 레이아웃이 아니라 자산 안에 들어 있다. 복제할 때 `object-fit: cover`로 흉내 내면 절대 같은 그림이 안 나온다.

배경색도 마찬가지다. MacBook Air·iPad Air 타일의 하늘색은 CSS 그라데이션이 아니라 **사진의 배경**이고, CSS `background-color`는 #f5f5f7로 두어 로딩 중·오차 영역만 받친다. 사진과 타일이 색으로 이어 붙는다.

**워드마크는 텍스트가 아니라 이미지다.** 브랜드 고정 표기(iPad Air의 필기체 *air*, WATCH SERIES 11,  Trade In,  Card)는 `.tile-headline.logo-image` PNG로 나가고, 일반 제품명(iPhone·MacBook Air·MacBook Pro·iPad Pro)만 라이브 타이포다. 자간·로고 조합이 걸린 것만 이미지로 잠근다.

정보성 자산 24개 전부 고유. 장식 일러스트·아이콘 카드 **0개**.

## 인터랙션

**호버는 거의 안 움직인다.** 이동·확대·그림자·밑줄 전부 없음.

```
1차 버튼   bg rgb(0,113,227) → rgb(0,118,223)     — 색차 5/255. 눈에 겨우 걸리는 정도
2차 버튼   투명·파란 보더 → 파란 채움·흰 텍스트·보더 투명   (유일하게 뚜렷한 변화)
내비 링크  rgba(0,0,0,.8) → rgb(0,0,0)            — 알파만 0.2 올림
갤러리 카드 변화 없음
```

**모션 언어** (전이 선언 인구조사)

```
지속시간  0.32s ×235(지배) · 0.24s ×108 · 0.22s ×25 · 0.18s ×25 · 0.2s ×22
이징     cubic-bezier(0.4, 0, 0.6, 1) ×251 — 대칭 ease-in-out 단일 · ease ×214
속성     color 235 · opacity 216 · transform 214 · width 9 · background-color 7
스타일시트 내 `transition: all` 선언 0건
```

0.32s 하나가 235곳을 덮는다. 속도를 요소마다 다르게 주지 않는다.

**스크롤 리빌 0건.** 페이드인·슬라이드업이 한 곳도 없다. 정지 상태에서 안 보이는 텍스트 14건은 전부 닫힌 내비 서브메뉴였고, 전체 스크롤 후 재검해도 리빌은 0이다. 업계 기준으로 통하는 사이트가 스크롤 애니메이션을 아예 안 쓴다.

**고정 요소 3개**: 내비(fixed, z 9999) · 서브메뉴 커튼(rgba(232,232,237,.4) + blur(20px), `opacity .32s cubic-bezier(.4,0,.6,1) .08s` — 80ms 지연으로 커튼이 메뉴보다 늦게 깔린다) · 지역 배너.

**비디오 4개 전부 `autoplay:false`, `muted:true`, `loop:false`.** 히어로는 정지 프레임(`startframe`) 이미지가 먼저 서고 재생은 선택이다.

**접근성**: 키보드 Tab 시 2px rgb(0,113,227) 포커스 링(offset −7px 안쪽). 각주 마커는 `<span class="footnote" aria-label="Footnote * symbol">` / `<sup>`로 의미가 붙는다. 갤러리에 명시적 일시정지 컨트롤. 단, `prefers-reduced-motion: reduce`에서도 내비 전이(0.32s)는 그대로 남는다.

## 배울 것

1. **사진 폭 = 타일 폭 × 1.8~2.1, 높이는 정확히 일치.** 세로는 안 자르고 가로만 자른다. 반응형 대응이 자산 한 장으로 끝난다
2. **타일 배경색을 사진이 가져오게 한다.** CSS는 같은 색으로 받치기만. 사진과 면이 이어 붙어 "얹은 이미지" 느낌이 사라진다
3. **다크 타일을 리듬이 아니라 등급 표시로 쓴다.** Pro 2종만 검정, 서비스 행에서는 교대를 끊는다. 밝음/어둠 교대는 의미가 있을 때만
4. **`<br>`을 한 개도 안 쓴다.** 줄바꿈은 타일별 맞춤 `max-width`(570/295/265/290px, 한 줄이면 `none`) + 갈라지면 안 되는 어절에 `&nbsp;`("in&nbsp;credit", "trade&nbsp;in", "iPhone&nbsp;13", "Daily&nbsp;Cash"). 반응형에서 안 깨지는 줄바꿈 통제법
5. **트래킹 부호를 크기 따라 뒤집는다.** 56/40px 음수 → 28/21px **양수** → 17/14/12px 음수. 전역 한 값은 큰 글자를 헐겁게, 중간 글자를 답답하게 만든다
6. **무게 2종(400/600), 폰트 광학 전환 1회(21px 경계).** 웨이트를 늘리는 대신 크기와 여백으로 위계를 만든다
7. **섹션 간격이 12px다.** 80px 패딩으로 벌리지 않는다. 여백은 타일 **안**에 있다 — 상단→헤드라인 56px, CTA 하단→타일 끝 375~407px(히어로 692 중 절반 이상이 사진 영역)
8. **호버 색차 5/255.** 1차 버튼은 사실상 안 변한다. 크게 변하는 건 2차 버튼(외곽선→채움) 하나뿐 — 변화를 아껴 쓰면 그 하나가 강해진다
9. **전이 하나로 통일**: 0.32s + cubic-bezier(0.4, 0, 0.6, 1). `transition: all` 선언 0건
10. **스크롤 리빌 0건**으로도 프리미엄이 성립한다. 페이드인이 품질의 조건이 아니다
11. **"Learn more"가 채움(1차), "Buy"가 외곽선(2차).** 커머스인데 구매보다 탐색에 시각적 무게를 준다. 하드웨어 타일 전부 이 쌍 고정, 서비스 타일만 동사구 단일("Get your estimate"/"Apply now")
12. **워드마크는 이미지, 제품명은 텍스트.** 자간이 브랜드 자산인 표기만 PNG로 잠근다
13. **알약(radius 980px) 하나로 버튼 형태 통일**, 크기만 2단(h44/h36). 카드 radius 0으로 대비를 만든다
14. **법률 문구를 접지 않는다.** 12px로 펴서 980폭에 그대로 싣는다

## 버릴 것

- 푸터 법률 블록 980px × 12px(≈160자/행) — 행폭·크기 둘 다 가독 하한 미달(QF3·QF4). 문구를 다 보여주려는 선택이지만 읽히지는 않는다
- 이미지 31개 `width`/`height` 미지정(QF6) — 래퍼 고정으로 버티는 중이라 CLS 노출이 남아 있다
- `prefers-reduced-motion: reduce`에서도 전이가 살아 있다 — 색 전이라 위해는 낮지만 존중 선언은 아니다
- 갤러리 카드 호버 무반응 — 클릭 가능한 943×523 면인데 커서 외에 단서가 없다
- **배율만 흉내 내는 것**: 56px는 여백·사진 프레이밍과 같이 와야 성립한다. 폰트만 키우면 그냥 큰 글씨다

### 시각 확인 (shot-1440.png · shot-390.png 직접 확인)

**IR이 5로 세는 이유(tree로 확인한 실제 구조):**

`ir.mjs`의 "바깥쪽 우선 · y중복 70%↑는 동일 섹션" 규칙이 래퍼를 남기고 타일을 버린다. **타일 기하 자체는 tree에 온전히 있다**(692 / 580). 즉 측정 실패가 아니라 증류 단계의 입도 문제이고, 브리프에서 타일 레벨로 내려가면 복구된다. 위 Tier-S 문서의 "타일 10개(히어로 3 + 프로모 6 + 갤러리 1) + 푸터"와 정확히 일치한다.

**시그니처 순간(실제로 본 것만):**
- 히어로 첫 타일 안의 **인라인 자동재생 비디오**(`inline-media-wrapper.playing.loaded`, y=346 h=460) — 나머지 타일은 정지 이미지
- **컷아웃 인물 합성** — 배경을 지운 학생 3인이 상자를 든 채 회색 판 위에 떠 있다
- 프로모 그리드의 **명암 교대** — iPad air(연하늘) ↔ MacBook Pro(검정), Watch(연회색) ↔ iPad Pro(검정)를 좌우로 엇갈리게 배치
- **Endless entertainment. 가로 갤러리** — 카드가 뷰포트 밖으로 흘러나가고 하단에 도트 7개 + 다음 화살표. 3초 자동 넘김(`dotnav-timed-animation 3000ms`)

- 스크롤 리빌은 **정말로 없다** — record의 reveal 0건이 위 Tier-S의 "스크롤 리빌 0건"과 교차 일치한다. 계기 결함이 아니라 사이트의 성질이다.

### 복합 위젯 (기계 기록 불가 → 기술로)

- **Endless entertainment. 갤러리**: 가로 스크롤 트랙 + 도트 내비 + 다음 버튼. 도트를 누르면 해당 세그먼트로 점프하고, 무조작 시 3초마다 진행한다(`progress-indicator-animating` / `segment-out` / `dotnav-shift-start|end`가 그 어휘). 카드 폭이 뷰포트보다 넓어 좌우가 잘린 채 노출되는 것이 의도된 상태다.
- **글로벌 내비 메가메뉴**: `globalnav-curtain`(backdrop-filter 보유, glassNodes=1)이 열릴 때 높이를 애니메이션(`globalnav-scrim-height-change`)하고, 메뉴 간 이동은 `flyout-slide-forward/back-next/previous` 4종으로 방향을 구분한다. 검색은 별도 5종(`search-fade`, `search-fade-and-slide`, `search-input-intro/outro`, `search-slide-top-to-bottom`).
- **지역 리디렉트 배너**: 국가 셀렉트 + 계속/닫기. 이번 수집에서 유일하게 실측된 hover(배경 2단계)가 여기 있다.
