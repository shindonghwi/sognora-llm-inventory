## 자산 운용

- **모든 카드 안에 제품 실화면이 들어간다.** 아이콘으로 때우는 카드가 0장이다 — 330×320 / 242×320 / 430×383 / 560×492 실캡처가 카드마다 하나씩. 캡션은 **굵은 첫 구절 + 회색 설명** 한 덩어리(`Secrets stay invisible to AI` + 설명).
- **브랜드 아이콘 벽 24개**(LinkedIn·Slack·Gmail·X·Canva·YouTube·Amazon·Google Drive…)를 3행으로 기울여 흩뿌린다. "통합 지원" 목록이 아니라 **"웹을 그냥 쓴다"는 주장의 증거물**로 배치된다. 제휴를 주장하지 않고 로고 벽 클리셰도 피한다.
- 감사 로그 카드는 `Geist Mono 12/500/-0.3px`로 호스트명(github.com·bofa.com·instagram.com)과 타임스탬프를 찍는다 — **모노 폰트를 신뢰 장치로** 쓴다.
- 히어로 배경은 `background.webp` 1장(bg-cover·rounded-xl·shadow) — 하늘 사진 위에 검은 글씨. 그라데이션 배경 4곳(CO2)은 전부 카드 내부의 파스텔 면이다.

## 인터랙션 (probe.mjs 실측 + 직접 조작)

### 호버 — 알파 하나로 끝낸다

| 대상 | 전 → 후 | 비고 |
|---|---|---|
| 검정 CTA(Download·Download for macOS) | `#090B0C` → `#090B0C @ .8` | 배경 알파만 |
| "Backed by YC" 필 | 투명 → `foreground @ .05` | 옅은 필 |
| 일러스트 일시정지 버튼 | opacity 0 → 0.9 | 필요할 때만 나타남 |
| 내비 링크 6종 | **변화 없음**(hoverDead) | 색 전환도 없음 |

**transform·그림자·크기 변화 0건.** forge-rules §2 인터랙션 언어(색 전환·알파 필·brightness만)와 정확히 일치하는 표본이다.

### 모션 언어 — duration 1개, easing 1개

- duration: **0.15s ×17** + 0.2s ×1 · easing: **`cubic-bezier(0.4, 0, 0.2, 1)` ×18**(단일). 흔들림이 없다.
- transition 속성은 Tailwind `transition-colors` 묶음(color·background-color·border-color·outline-color·fill·stroke) — `transition: all` 아님.
- `@keyframes` 15개: `show-top-mask` · `hide-bottom-mask`(마스크 페이드) · `subscription-marquee`(목업 안 마퀴) · `thinking-gradient`(AI 사고 중 그라데이션) · `spin` · `pulse` + sonner 토스트 세트.
- 스크롤 리빌: 정지 시 숨김 9개 → 스크롤 후 7개 등장. 남은 2개는 뷰포트 밖 요소.
- 고정 내비 1개(`sticky top-0 z-50`, `font-display`).

### "영상 같다 / 마우스가 움직인다"의 실체 — 실측 결과

사람 눈에 영상처럼 보이는 구간의 정체를 계기로 확인했다.

- **동영상은 한 개도 없다.** `<video>` 0개 · iframe 0개(GTM 제외) · media 리소스 요청 0건 · mp4/webm 0건.
- **캔버스 3개(각 383×320, y=2207)가 자기 스스로 다시 그린다.** 마우스를 대지 않은 상태에서 0.7초 간격 두 샘플의 픽셀 해시가 서로 다름(`animatesOnTime: true`), rAF 1초당 **120회 예약**(≈60fps). "Unlimited capability" 구간의 파스텔 그라데이션 타일이 이것이다.
- **마우스 추적은 없다.** 페이지가 등록한 리스너를 `addInitScript`로 후킹해 전수 집계한 결과 `pointerdown` 74 · `pointerenter` 48 · `click` 31 … 인데 **`mousemove`·`pointermove`는 0건**이다. 커서를 따라오는 효과처럼 느껴지는 것은 ⓐ 캔버스 자가 애니메이션 ⓑ 다크 패널 안에 **그려 넣은 커서 일러스트**("Aside" 라벨이 붙은 화살표) ⓒ 0.15s 호버 전환의 합이다.
- 교훈: **움직임의 값어치는 입력 반응이 아니라 "제품이 일하는 장면"에서 나온다.** 마우스 추적 없이도 살아 있는 화면을 만든 표본으로 쓸 것.

## 배울 것

1. **히어로에 제품을 라이브로 세운다** — 스크린샷 대신 DOM 목업, 그 안에서 타이핑·경과시간·작업 카드가 실제로 돈다. 정지 이미지 한 장보다 "이 도구가 지금 일하고 있다"는 인상이 강하다. **단, 멈춤 버튼까지 만들어야 완성이다.**
2. **자랑은 표로 한다** — 실명 경쟁자 4곳과 나란히 놓은 막대 + 벤치마크 3종 탭 + 출처 링크. 형용사("가장 강력한") 대신 숫자와 이름을 놓으면 검증 가능해지고, 검증 가능한 주장은 신뢰가 된다.
3. **헤드라인이 개념을 연기한다** — `Password that ✱✱✱✱✱✱.` 마스킹 문자를 조판 요소로. 설명 문단을 한 개 줄인다.
4. **유채색 1계열 + 면적 최소** — sky 하나로 링크·1위 막대·최종 글로우만. 나머지 색은 전부 제품 화면 안에서 온다. 팔레트를 지키면서도 화면이 화려한 이유.
5. **가변 폰트의 중간 무게(450·550)** — 700을 한 번도 쓰지 않고 위계를 만든다. 한글에서도 500/800 대비로 옮겨 적용 가능(forge-rules §1b).
6. **격자 틀(border-x + border-b, 6% 검정)** — 섹션 경계를 배경색 교대가 아니라 헤어라인으로. 밝은 페이지에서 구조를 만드는 저비용 장치이고, 패딩을 섹션이 아니라 레일에 걸어 리듬을 일정하게 유지한다.
7. **카드마다 실화면 1장** — 아이콘 카드 0장. "카드 3장 나열"이 클리셰가 되는 건 안이 비었을 때뿐이라는 증거.

## 버릴 것

- **디스플레이 3.0×를 그대로 베끼지 말 것** — 히어로에 990px 목업과 풀블리드 사진이 있어서 성립한다. 그 무게를 못 만들면 헤드라인이 작아 보이고, 라이브러리 실측 밴드(4.1~7.2×)로 돌아가야 한다.
- **`background-clip:text` 그라데이션 텍스트**(CO5·🔴)가 히어로에 1건 있다. 채택 사유 없이 따라 하지 말 것.
- **아이콘 20개가 텍스트·aria 없이 배치**(IC3 🔴 sec0·sec4·sec5, 동일 SVG 6회 반복 IC1) — 접근성 부채다. 브랜드 아이콘 벽을 흉내 낼 때는 `aria-label`을 붙일 것.
- **모바일 44px 미만 탭 타깃 8개**(QF5, 390×844) · **width/height 미지정 이미지 10개**(QF6, CLS 위험). 이 사이트도 QF 하한은 다 못 지켰다.
- 폰트 사이즈 고유값 9개(TS1 🔴 문턱). 사다리가 촘촘한 대신 단 수가 많다 — 우리 규칙(5~8단)에서는 12/13, 44/48을 병합해야 한다.
