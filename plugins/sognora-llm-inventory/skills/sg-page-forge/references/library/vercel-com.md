## 실측 토큰 (capture.mjs + 라이브 DOM)

**타이포** — 자간이 이 사이트의 서명이다. 디스플레이 전 단계 `-0.06em`.

| 역할 | 크기/행간 | 굵기 | 자간 |
|---|---|---|---|
| h1 히어로 | 64px / 64px (**1.0**) | 400 | −3.84px (−0.060em) |
| h2 섹션 | 56px / 56px (**1.0**) | **450** | −3.36px (−0.060em) |
| 서브헤드(고객 문장) | 24px / 32px | 450 | −0.96px (−0.040em) |
| 본문 | 16px / 24px | 400 | normal |
| 라벨·푸터 제목 | 14px / 20px | 500 | normal |
| 푸터 링크 | 14px / 21px | 400 | normal |
| 터미널 | Geist Mono 14px / 20px | 400 | normal |

- **행간 = 폰트 크기**(64/64, 56/56). 디스플레이에서 leading 1.0을 쓰고 자간으로 밀도를 잡는다
- 굵기 **450**은 가변폰트 중간축 — 400과 500 사이. bold를 안 쓰고 위계를 만든다

**색 — 채도 0. `hsla(0, 0%, X%)`만 쓴다.**

| 토큰 | Light | Dark |
|---|---|---|
| body 배경 | 98% (#FAFAFA) | **0% (#000)** |
| background-100(카드면) | 100% | 4% |
| gray-200(경계) | 92% | 12% |
| gray-600(약한 텍스트) | 66% | 53% |
| gray-900(보조 텍스트) | 30% (#4D4D4D) | 63% |
| gray-1000(본문) | **9% (#171717)** | **93% (#EDEDED)** |

- 순수 검정 텍스트도, 순수 흰 배경도 없다(light). 반대로 dark는 배경만 순수 검정이고 텍스트는 93%
- 베이스(98%)와 카드면(100%)이 **2%만 다르다**. 카드를 띄우는 게 아니라 "겨우 구분"시킨다

**유채색 총량 — 페이지 전체에서 유채색 요소는 딱 2종.**

- Passport 카드 여권 책등의 5색 그라데이션 `#00FF95 → #FFD000 → #FF1744 → #9500FF → #00E5FF` — **48×243px 한 조각**
- 터미널 블록의 체크 3개 `rgb(41,122,58)` — 14×16px ×3
- 합계 약 12,300px² / 전체 7,680,000px² = **0.16%**. (그 외 `#0072F5`는 키보드 포커스 전용 skip 링크라 눈에 안 보임)

**레이아웃**

- 12칼럼 × 97.66px, `gap-x` 20px, 콘텐츠 폭 1392px, 페이지 max-width **1400px + 좌우 24px**
- 헤더 높이 **64px** 고정(sticky)
- 섹션 간격 `mt-52` = **208px**, 마감 CTA만 `mt/mb-69` = **276px**
- radius **두 값뿐**: 카드 6px, 알약 full. LA3가 "단일값 지배"로 잡았지만 실은 의도적 2값 체계
- **border를 안 쓴다.** 전부 이중 링 box-shadow: `0 0 0 1px rgba(0,0,0,.08)` + `0 0 0 1px #FAFAFA`. 레이아웃을 안 밀고 hairline이 더 또렷하다

## 자산 운용

- **장식 자산 0개.** 일러스트·블롭·아이콘 카드·추상 도형 전부 없음
- 고객 스크린샷 3장 × **4변형**(desktop-light / desktop-dark / mobile-light / mobile-dark) = 12파일. CSS 필터로 다크를 만들지 않고 **고객사 다크 테마로 다시 찍었다**
- 표시 크기 921px, 원본 950×500·633×355·950×532 — **거의 1:1**. 업스케일 없음
- **기기 프레임·브라우저 크롬·그림자 없음.** 대신 스크린샷 하단 160px를 `linear-gradient(to top in oklab, #FAFAFA, transparent)`로 **페이지 배경에 녹인다**. 카드에 담지 않고 바닥으로 소멸시키는 방식 — CO2가 "그라데이션 5곳"으로 잡았지만 5개 중 4개가 이 기능성 마스크다
- 고객 로고 7개 전부 인라인 SVG + `aria-label`. 컬러 로고에 grayscale 필터를 씌운 게 아니라 **단색 전용 SVG**를 받아 썼다
- 제품 데모 추상화 3단: ① 실제 고객 화면 원본(Notion/Zapier/Mintlify) ② 자체 제품은 선화 SVG 아트(eve 카드의 와이어 도형) ③ CLI는 **실제 터미널 출력 텍스트**를 Geist Mono로 그대로
- 다크 모드 전용 노이즈: 70×70px 타일 webp를 `opacity .42`로 히어로에 반복 — 순수 검정 배경의 밴딩을 죽인다
- canvas는 `opacity-0 → transition-opacity duration-1200 ease-linear`. 페이지에서 유일한 1초대 모션

## 인터랙션

**호버 표 (probe.mjs 14표본 · 무반응 7)**

| 대상 | 변화 | 값 |
|---|---|---|
| 네비 텍스트 링크 | color만 | `#4D4D4D → #171717` |
| 2차 버튼(Talk to sales·Get a Demo) | bg만 | `#FFF → #F2F2F2` |
| 1차 버튼(Sign Up·Deploy now·Get your ticket) | bg만 | `#171717 → #383838` |
| **Recently shipped 카드 3개** | **없음**(box-shadow·transform 전부 불변 — 3개 직접 확인) | — |
| 로고·아이콘 전용 링크 7개 | 없음(무반응) | — |

**호버 레시피가 페이지 전체에 3개뿐이다. transform·scale·lift·glow·border 변화 0건.**

**히어로 우측 링크 — 이 페이지 최고의 인터랙션**

정지 시엔 짧은 리드만 보인다: `For coding agents`.
호버하면 뒷문장이 **같은 문단 안에서** opacity 0→1(0.3s)로 켜지고 행이 1줄→3줄로 늘며 아래 두 항목을 밀어낸다.
`**For coding agents** to deploy in their native language, with Vercel's API, CLI, MCP, and Skills.`
리드는 gray-1000 유지, 이어지는 문장만 gray-900. 툴팁도, 패널도, 아코디언 셰브런도 없다. 뒷문장은 `aria-hidden="true"`이고 전체 문장은 부모에 남아 스크린리더에는 항상 완전하다.

**네비 드롭다운** — 패널을 안 그린다. 메뉴가 페이지 표면 위에 평평하게 열리고 하단에 hairline 한 줄. 대신 `fixed inset-x-0 bottom-0 top-64px` 스크림이 **헤더 아래 전체를 회색으로 낮춘다**(삼각형이 검정→회색, 헤드라인도 로고도 같이 내려앉음). 카드 그림자 대신 "나머지를 끈다".

**스크롤 리빌 — 0건.** 화면 밖 h2·이미지를 스크롤 전에 측정해도 `opacity:1 / transform:none`. 풀페이지 캡처에서 하단이 비어 보이는 건 `loading="lazy"` 디코딩 지연일 뿐 애니메이션이 아니다. **엔트런스 모션이 아예 없는 최상급 랜딩의 실증.**

**모션 언어**

- duration 분포: **0.1s ×79, 0.15s ×49**, 0.2s ×9, 0.3s ×1(히어로 텍스트 스왑), 1.2s ×1(canvas 페이드)
- easing: `cubic-bezier(0.4, 0, 0.2, 1)` ×137로 사실상 단일
- transition 대상: `color / background-color / border-color / outline-color / text-decoration-color / fill / stroke` 각 115건. **전부 색 속성.** `transition: all`은 14건뿐
- 즉, 이 사이트가 움직이는 방식은 **"0.1~0.15초 안에 색만 바뀐다"** 한 줄로 끝난다

**sticky**: 헤더 1개 + 우측 `aside h-screen`(피드백 위젯). 그 외 고정 요소는 스크림·드롭다운 컨테이너뿐

## 배울 것

1. **자간이 디스플레이 타이포의 본체다.** 64px/56px 전부 `-0.06em`, 24px는 `-0.04em`. 크기가 커질수록 자간을 더 조인다. 폰트를 안 바꿔도 이것만으로 급이 달라진다
2. **행간 1.0.** 디스플레이는 `line-height = font-size`. 두 줄 헤드라인이 한 덩어리로 뭉쳐 보이는 이유
3. **굵기 450.** bold 없이 400과 500 사이 가변축 한 칸으로 h2 위계를 만든다. `font-weight:700`은 페이지에 한 번도 안 나온다
4. **유채색 예산 0.16%.** 흑백 베이스에서 색은 "포인트"가 아니라 **배급제**다. 48px짜리 여권 책등 하나와 체크 3개. 색을 쓰고 싶으면 이 정도 면적에서 시작해라
5. **순수 검정/흰색 금지(light).** 배경 98%, 텍스트 9%. 대신 dark는 배경만 0%로 떨어뜨리고 텍스트를 93%에 둔다 — 두 테마의 규칙이 대칭이 아니다
6. **border 대신 이중 링 그림자.** `0 0 0 1px rgba(0,0,0,.08)` + 배경색 링. 레이아웃 시프트 없고 hairline이 더 선명하다
7. **스크린샷을 카드에 담지 말고 바닥에 녹여라.** 하단 160px를 페이지 배경색 그라데이션으로 소멸. 프레임·그림자·라운드 전부 불필요해진다
8. **A·B·A 미러링으로 3섹션 반복을 지운다.** 같은 템플릿을 좌–우–좌로 뒤집기만 해도 "카드 나열" 인상이 사라진다. 헤드라인 x좌표까지 같이 뒤집는 게 핵심(24 → 495 → 24)
9. **한 문장 두 톤 강조.** 수치 절만 gray-1000, 나머지 gray-900. 굵게·색·하이라이트 없이 명도 21%p로 끝낸다
10. **호버 레시피 3개로 사이트 전체를 덮는다.** 색만, 0.1~0.15초, 단일 이징. 카드 호버는 아예 안 준다 — 링크가 아닌 척하지 않고, 링크인 척도 하지 않는다
11. **엔트런스 애니메이션 0.** 스크롤 리빌·페이드업·스태거 전부 없이 최상급으로 읽힌다. 리빌은 품질의 조건이 아니다
12. **로고 크기를 통일하지 마라.** 높이 17~45px로 제각각 두고 시각 무게로 맞춘다. 균일 박스에 넣는 순간 아마추어가 된다
13. **히어로를 기능으로 만들어라.** "Drop to deploy" — 히어로 그래픽이 실제 드롭존이다. 제품 시연을 그림으로 그리는 대신 히어로에서 제품을 쓰게 한다
14. **다크 테마 자산은 다시 찍어라.** 필터가 아니라 desktop/mobile × light/dark 4변형 파일. 고객 화면을 고객사 다크 테마로 받아온다
15. **기능 목록은 평문 4줄.** `Features` 라벨(14px gray-600) 아래 기능명만. 아이콘도 불릿도 카드도 설명문도 없다

## 버릴 것

- **폰트 스택 통째 복제**(GeistSans는 Vercel의 사명 폰트다 — 배울 건 폰트가 아니라 `-0.06em`과 leading 1.0)
- **검정 삼각형 아우라**(다크 배경 + 실루엣 + 방사 글로우)는 이미 Linear glow와 같은 경로를 밟는 중. 형태를 베끼면 클리셰
- **흑백만 남기고 끝내기.** 이 사이트의 저채도는 12파일짜리 실고객 스크린샷과 자체 SVG 아트가 채워주기 때문에 성립한다. 자산 없이 흑백만 가면 그냥 빈 페이지다(밀도 36.6%는 콘텐츠가 지탱하는 수치)
- **radius 6px 단일화**를 그대로 가져오기 — LA3에 걸린다. Vercel은 6px과 full **두 값**을 역할로 나눠 쓴다(면=6, 인터랙티브=full). 한 값만 쓰면 티다
- **무라벨 아이콘 링크**(IC3 9건) 흉내 — 실제 호버 무반응 7건이 여기서 나왔다. Vercel의 실패 지점이지 배울 점이 아니다
- **본문 11~12px**(QF4 3건) — 푸터 뱃지에서 하한을 깼다. 따라할 이유 없음
