# mayoclinic.org 분석

장르/단위: 의료 기관(비영리 병원·영어) / 홈 · 분석일 2026-08-15 · 상태: **완전**

측정 조건: 1440×900 · light · detect.mjs + probe.mjs + capture.mjs + fetch-assets.mjs + 라이브 headed 실측(뷰포트 슬라이스 7컷 · 호버 9표본 · Tab 14회 · 스크롤 상태 4지점).
전체 높이 **5,407px**(6.0뷰포트) · DOM 2,598개 · 가시 텍스트 노드 150개 · 이미지 11개 · 인라인 SVG 191개.

> **측정 메모 — 봇월 우회.** mayoclinic.org는 Akamai가 **헤드리스 크롬을 403 Access Denied로 차단**한다(스캐너 첫 실행 결과: 섹션 1개, 내용은 "Access Denied"). `--headed`로는 통과하지만 이번엔 애널리틱스 비컨이 끊이지 않아 스크립트에 하드코딩된 `waitUntil: "networkidle"`(45s)에 영영 도달하지 못한다. 그래서 headed 크롬으로 원본을 열어 **응답 바디를 전부 기록한 자기완결 미러**를 만들고(스크립트 제거 → networkidle 즉시 도달) 로컬 서빙해 4개 도구를 돌렸다. 미러 높이 5,343px vs 라이브 5,407px로 **오차 1.2%**. 색·타이포·기하는 전부 아래 라이브 실측값을 정본으로 쓴다. fetch-assets를 원본 URL에 직접 쏘면 폰트 4종이 403으로 떨어지지만, 그 403 로그가 오히려 **실제 폰트 파일명**(`MayoClinicSerifDisplay-Bold.woff2` 등)을 드러냈다.

## 수치

### 타이포 — 페이지 전체가 폰트 사이즈 5단으로 돈다

가시 텍스트 노드 150개의 사이즈 고유값은 **6개뿐**: `13.33 16 20 24 40 76`.

### 이 페이지의 핵심 — 행간 비율이 미학이 아니라 4px 그리드의 해(解)다

토큰을 뜯으면 사이즈와 행간이 **같은 인덱스로 짝지어져** 있다. `font-size-10x` ↔ `line-height-10x`.

| 토큰 인덱스 | font-size | line-height 비율 | 곱 = 실제 행간 |
|---|---|---|---|
| 3x | 12 | 1.3333 | **16** |
| 4x | 16 | 1.5 | **24** |
| 5x | 20 | 1.4 | **28** |
| 6x | 24 | 1.3333 | **32** |
| 8x | 32 | 1.25 | **40** |
| 10x | 40 | 1.1 | **44** |
| 12x | 48 | 1.0833 | **52** |
| 15x | 60 | 1.0667 | **64** |
| 19x | 76 | 1.0526 | **80** |

**9쌍 전부 4의 배수로 떨어진다.** 1.0526, 1.0667, 1.0833 같은 소수점 4자리 비율은 감으로 고른 값이 아니라 `76×n=80`, `60×n=64`, `48×n=52`를 만족하도록 **역산한 값**이다. "커질수록 행간 배율을 낮춘다"는 정석이 여기서는 규칙이 아니라 **연산 결과**로 나온다.

그리고 이 규칙이 깨진 자리가 페이지에 딱 하나 있다. **기부 밴드 H2가 size-10x(40)에 lh-8x(1.25)를 물려 50px**을 만들었다 — 페이지에서 유일하게 4의 배수가 아닌 표제 행간이다. 3줄짜리 제목을 어두운 배경에서 숨 트이게 하려고 인덱스를 어긋나게 쓴 것이고, 그 순간 그리드가 깨진다. **시스템이 옳다는 증거는 예외가 어떻게 실패하는지에서 나온다.**

(다행 링크 리스트의 20.4px도 4의 배수가 아니다. `1.02rem × 20px root`로 보이며, 비율 토큰이 아니라 절대값을 쓴 자리다.)

### 기하

- 그리드: `--mc-grid-max-width: 1320px` / `--mc-max-site-width: 1296px`. 1440에서 x=60에 1320 배치.
- **3컬럼 440px 등간격**(x=60 / 500 / 940). 내부 패딩 12px씩 → 콘텐츠 416px, 텍스트 블록 404px.
- 에디토리얼 모듈은 별도: 텍스트 404px + 사진 **526px**.
- 간격 토큰 `--mc-spacing-Nx = N × 8px`(0.5x=4 … 64x=512). 실제 최다 사용은 **12px**(13회).
- 루트 폰트 사이즈가 **20px**(`--mc-typography-font-size-root: 20`). 그래서 rem 계산이 16 기준이 아니다.
- radius 토큰 8단(0/4/8/12/16/24/32/1000). 실사용: **1000px×58, 8px×28**, 24/32/16/48 각 1~4회.
- **`box-shadow`를 가진 요소 0개.** 페이지 전체.
- **`position: fixed`/`sticky` 요소 0개.**

### 이 페이지에서 실제로 확인된 값

```css
/* 서체 */
--mc-typography-font-family-display: mayo-display, Georgia, serif;
--mc-typography-font-family-serif:   mayo-serif, Georgia, serif;
--mc-typography-font-family-sans:    mayo-sans, Arial, 'Helvetica Neue', sans-serif;
--mc-typography-font-size-root: 20;                    /* rem 기준이 16이 아니다 */
--mc-typography-font-weight-light: 300;  --regular: 400;  --bold: 700;

/* 사이즈 ↔ 행간 (같은 인덱스끼리만 짝) */
--mc-typography-font-size-4x: 16;   --mc-typography-line-height-4x: 1.5000;
--mc-typography-font-size-5x: 20;   --mc-typography-line-height-5x: 1.4000;
--mc-typography-font-size-6x: 24;   --mc-typography-line-height-6x: 1.3333;
--mc-typography-font-size-10x: 40;  --mc-typography-line-height-10x: 1.1000;
--mc-typography-font-size-19x: 76;  --mc-typography-line-height-19x: 1.0526;

/* 색 — 페이지에 실제로 나타난 것만 */
--mc-color-action-primary-default: #0057b8;   /* 링크·CTA·칩 */
--mc-color-text-action-hover:      #1371d5;   /* 호버 = 이 한 값 */
--mc-color-text-action-pressed:    #002443;
--mc-color-text-action-visited:    #670081;   /* visited를 버리지 않았다 */
--mc-color-layer-tertiary-default: #080808;   /* 본문 니어블랙 */
--mc-color-text-secondary:         #686868;
--mc-color-text-caption:           #595959;
--mc-color-background-primary:     #ffffff;
--mc-color-background-donations:   #0d0d33;   /* 기부 밴드 전용 토큰 */
--mc-color-signal-warning-default: #ffc845;   /* 경고 밴드 */
--mc-color-signal-error-default:   #e4002b;
--mc-color-icon-interactive-container-default: #afd7ff;
--mc-color-icon-interactive-inverse-pressed:   #8cc5ff;  /* A–Z 칩 테두리와 같은 값 */
--mc-color-border-primary-inverse-hover:       #e1f0ff;  /* 저작권 밴드 배경과 같은 값 */

/* 기하 */
--mc-grid-max-width: 1320px;   --mc-max-site-width: 1296px;
--mc-layout-gutter-size: 16;   --md: 24;   --lg: 32;
--mc-spacing-1x: 8;            /* Nx = N × 8px */
--mc-radius-small: 8;   --mc-radius-x-large: 24;   --mc-radius-full: 1000;

/* 모션 — 사이트 전체가 이 두 줄 */
--mc-transition-timing: 0.3s;
--mc-transition-easing: ease-in-out;

/* 포커스 */
--mc-focus-outline-width: 2px;   --mc-focus-outline-style: dashed;
--mc-focus-outline-offset: 3px;  --mc-focus-outline-border-radius: 3px;
--mc-color-focus-primary: #0057b8;   --mc-color-focus-primary-inverse: #ffffff;
```

읽을 만한 지점 3개:

1. **`background-donations`가 색 토큰으로 존재한다.** 브랜드 팔레트가 아니라 *용처* 이름을 단 배경 토큰이다. 기부 밴드의 `#0D0D33`은 어느 브랜드 컬러의 변형도 아니고, 그 자리에서만 쓰라고 만든 값이다.
2. **`signal-*` 계열이 브랜드와 분리돼 있다.** warning / error / success / neutral 4종 × 상태별. 경고 밴드의 노란색은 디자인 결정이 아니라 상태 값이라서, 고지가 뜰 때 디자인 논의가 필요 없다.
3. **`text-action-visited: #670081`이 라이트/인버스 쌍으로 정의돼 있다**(inverse는 `#c268d9`). 방문 링크 색을 팔레트에서 지우지 않았다는 뜻이다. 질환 정보를 뒤지는 사람에게 "어디까지 읽었는지"는 기능이고, 대부분의 현대 사이트가 제일 먼저 버리는 자리다. (홈에는 방문 링크가 노출되지 않아 적용 여부까지는 이 페이지에서 확인되지 않는다.)

## 자산 운용

이미지 **11개뿐**. 5,407px 페이지에서. 그중 사진은 **7장**이고 나머지 4개는 로고·아이콘·앱배지 SVG다.

- **사진 종횡비가 2종으로 고정.** 에디토리얼 2장은 600×800(3:4 세로), 위치 카드 5장은 654×490(4:3 가로). 렌더 526×701 / 416×312.
- **원본 대비 배율이 1.14~1.57배.** 2x 레티나 자산이 아니다. 기관 사이트가 대역폭을 어디에 쓰는지 보여주는 선택.
- 사진 radius는 전부 **8px**(`--mc-radius-small`). 각지지도, 크게 둥글지도 않다.
- 위치 카드 5장의 텍스트 가독성은 **스크림 그라디언트 1개**로 해결: `linear-gradient(rgba(0,0,0,0) 27.4%, rgba(0,0,0,0.56) 58.85%, rgba(0,0,0,0.8) 100%)`. 이 **똑같은 그라디언트가 히어로 오버레이에도 그대로 쓰인다**(6회 등장). 스크림 토큰 하나, 용처 둘.
- 재생 버튼 배경이 `rgba(0,0,0,0.56)`, 호버 시 `rgba(0,0,0,0.8)`. **스크림 그라디언트의 두 정지점 알파와 정확히 같은 값**이다. 알파 사다리가 하나다.
- 인라인 SVG **191개** — 거의 전부 셰브런과 소셜·유틸 아이콘. 아이콘은 이미지가 아니라 DOM이다.
- `img` 11개 전부 `loading="lazy"`, 그리고 **11개 전부 width/height 속성 없음**(CLS 위험).

폰트: **자체 서체 3종 패밀리** — `mayo-display`(세리프 디스플레이) / `mayo-serif`(텍스트 세리프) / `mayo-sans`. `@font-face` **18건 선언, 실제 로드 5개**(display 300·700, sans 400·700, serif 700). 폴백은 display·serif → Georgia, sans → Arial → Helvetica Neue.
추가로 **Tajawal(아랍어) 7웨이트**가 선언돼 있고 `--mc-rtl-*` 토큰 4종(`rtl-flip-horizontally`, `rtl-transform-icon-chevron-right`, `rtl-transform-icon-tap-ahead`, `rtl-search-button-radius`)이 있다. **RTL이 사후 대응이 아니라 토큰 레벨에 박혀 있다.** 검색 버튼 radius조차 좌우 반전을 계산해 넣은 별도 토큰이다.

### 세리프/산세리프 분업

계산된 `font-family` 기준 요소 수(래퍼 span 포함):

- `mayo-display`(46요소): H1, 섹션 H2, 카드 제목 — **이름을 부르는 자리**
- `mayo-serif`(58요소): **푸터 칼럼 헤더 전용**. 실제 헤더는 9개(20px/700 7개 + 16px/700 2개)
- `mayo-sans`(486요소): 본문, 내비, 링크, 라벨, 버튼 — **설명하는 자리**

규칙은 한 줄이다. **명명은 세리프, 서술은 산세리프.** 푸터 링크 그룹의 제목까지 세리프인 이유가 이거다 — 그건 문장이 아니라 이름이니까.

## 인터랙션

### 모션 어휘 (probe 실측)

```
duration: 0.3s × 6        easing: ease-in-out × 6
property: opacity × 4, background-color × 2
transition: all → 0건
```

토큰도 정확히 둘뿐이다: `--mc-transition-timing: 0.3s`, `--mc-transition-easing: ease-in-out`. **사이트 전체에 duration 1개, easing 1개.**

### 호버 (라이브 9표본)

| 대상 | 변하는 것 | from → to |
|---|---|---|
| 헤더 `Request appointment` | color | `#080808` → `#0057B8` |
| A–Z 칩 | color | `#0057B8` → `#1371D5` |
| 인라인 본문 링크 | **밑줄 제거** | underline → none |
| 히어로 텍스트 링크 | **밑줄 추가** | none → underline |
| 푸터 박스 링크 | border alpha | `rgba(255,255,255,.15)` → `#FFFFFF` |
| 법적 고지 링크 | color | `#080808` → `#1371D5` |
| 재생 버튼 | bg alpha | `rgba(0,0,0,.56)` → `rgba(0,0,0,.8)` |
| **`Give Today`(채운 CTA)** | — | **무반응** |
| **사진·아웃라인 필·소셜 필** | — | **무반응** |

**9표본 전부 transform 0건, box-shadow 0건, scale 0건.** 뜨는 것도, 커지는 것도, 사진이 확대되는 것도 없다. 바뀌는 건 색·알파·밑줄뿐이다.

밑줄 처리가 특히 정교하다. **문장 속 링크는 평상시 밑줄이 있고 호버에서 사라진다. 독립 CTA 링크는 평상시 밑줄이 없고 호버에서 생긴다.** 방향은 반대지만 목적은 같다 — *링크임을 호버에 의존해 알리지 않는다.* 본문 링크는 마우스를 안 올려도 이미 링크로 보이고, 호버는 "지금 여기"만 표시한다.

### 포커스 — Tab 14회 전수

```
outline: 2px dashed #0057B8    outline-offset: 3px
어두운 밴드 위: 2px dashed #FFFFFF (inverse 토큰)
```

토큰이 5개나 있다: `--mc-focus-outline-width: 2px`, `--mc-focus-outline-style: **dashed**`, `--mc-focus-outline-offset: 3px`, `--mc-focus-outline-border-radius: 3px`, `--mc-color-focus-primary` / `-inverse`.

A–Z 칩에 포커스가 가면 **칩의 실선 테두리(`#8CC5FF`)가 진해지고 그 바깥 3px 지점에 점선 링이 하나 더 생긴다.** 실선/점선 두 겹이라 "테두리 있는 요소"에서도 포커스가 테두리에 묻히지 않는다. 점선을 고른 이유가 이거다.

### 스크롤 — 아무 일도 안 일어난다

- **정지 상태 은닉 0건, 스크롤 후 발화 0건.** 페이드인·슬라이드업 리빌이 **하나도 없다**.
- **sticky/fixed 요소 0개.** 헤더는 `position: static`이라 4지점(0/300/1500/3000px) 측정 전부 `rectTop = -scrollY` — 그냥 위로 밀려 사라진다.
- 5,407px를 내리는 동안 화면에 고정되는 것도, 나타나는 것도 없다. **스크롤이 순수한 이동이다.**

### CTA 위계 — 페이지에 채운 버튼이 하나뿐이다

`background: #0057B8`인 요소를 전수 조회하면 **정확히 1개**가 나온다.

| CTA | 형태 |
|---|---|
| 헤더 `Request appointment` | 순수 텍스트. 버튼 아님 |
| 히어로 `Request appointment` | 흰 2px 아웃라인 필, 채움 없음 (232×48) |
| `Why choose Mayo Clinic` / `International services` / `Explore all locations` | 블루 2px 아웃라인 필, 채움 없음 |
| 푸터 `Find a doctor` / `Explore careers` / 뉴스레터 | 반투명 2px 테두리 박스, radius 8px |
| **`Give Today`** | **`#0057B8` 채움 + 흰 텍스트, 306×52, radius 24px** |

병원 홈페이지에서 가장 큰 소리로 말하는 버튼이 **진료 예약이 아니라 기부**다. 예약은 헤더에서 평범한 텍스트로, 히어로에서 속 빈 아웃라인으로 두 번 나온다. 비영리 기관이 자기 정체를 시각 위계로 진술한 것이고, 상업 사이트가 이걸 그대로 베끼면 그냥 전환을 버리는 짓이 된다.

## 배울 것

1. **행간 비율을 감으로 고르지 말고 4px 그리드의 해로 역산해라.** 실측 9쌍이 전부 4의 배수로 떨어진다(76×1.0526≈80, 60×1.0667≈64, 48×1.0833≈52, 40×1.1=44, 32×1.25=40, 24×1.3333≈32, 20×1.4=28, 16×1.5=24, 12×1.3333≈16). H1의 계산값은 실제로 `79.9976px`다 — 1.0526은 예쁘라고 있는 게 아니라 **80을 만들려고 소수점 4자리까지 역산한 값**이고, 그 반올림 오차가 증거다.

2. **사이즈 토큰과 행간 토큰을 같은 인덱스로 묶어라.** `font-size-10x`는 `line-height-10x`와만 짝이 된다. 이러면 짝을 틀리는 게 물리적으로 어려워지고, 틀린 자리는 즉시 눈에 띈다 — 실제로 이 페이지에서 유일하게 그리드를 깬 값(기부 H2의 50px)이 인덱스를 어긋나게 쓴 바로 그 자리다.

3. **기관의 격은 폰트 단 수를 줄이는 데서 나온다.** 눈에 보이는 사이즈가 **5단**(76/40/24/20/16), weight **3종**, 텍스트 색 **4개**, 실질 3개. 5,407px 페이지 전체가 이걸로 돈다. 신뢰가 전부인 페이지에서 다양성은 비용이지 자산이 아니다.

4. **세리프는 명명, 산세리프는 서술로 나눠라.** display 세리프는 H1·H2·카드 제목에만, 텍스트 세리프는 푸터 칼럼 헤더에만, 나머지 486요소는 전부 산세리프. "무엇의 이름인가 / 무엇을 설명하는가"라는 한 줄 규칙으로 3서체를 굴린다. 장식으로 세리프를 뿌리는 것과 정반대다.

5. **본문 구간 배경을 한 값으로 두고 모듈 반전으로 리듬을 만들어라.** 흰색 3,251px 연속, 교대 배경 0회. 대신 사진이 우→좌로 뒤집히고(섹션 4↔5), 그다음 두 섹션은 표제를 왼쪽 열에 고정한 채 오른쪽 콘텐츠만 바꾼다. 배경을 번갈아 까는 것보다 조용하고, 조용한 게 기관에는 신뢰다.

6. **경고를 브랜드 색이 아니라 신호 토큰으로 분리해라.** 히어로 바로 아래 71px 노란 밴드는 `--mc-color-signal-warning-default`다. `signal-{warning|error|success|neutral}` 계열이 브랜드 팔레트와 별도로 존재한다. 이러면 "환자 정보 유출 고지" 같은 게 떴을 때 **디자인을 협상하지 않고 밴드 하나 켜면 끝난다.** 의료·금융처럼 법적 고지가 상시 발생하는 도메인의 필수 장치.

7. **호버는 색·알파·밑줄만. transform과 shadow는 0.** 9표본 전수 확인. 그리고 `box-shadow`를 가진 요소가 페이지에 **하나도 없다**. 카드가 들리는 효과는 잘 만든 사이트의 표식이 아니다 — 오히려 기관 사이트에서는 경박함의 표식이다.

8. **링크임을 호버에 의존해 알리지 마라.** 문장 속 링크는 평상시 밑줄 ON → 호버에서 OFF, 독립 CTA는 평상시 OFF → 호버에서 ON. 방향이 반대인 두 규칙이 같은 목적을 지킨다: 마우스를 올리기 전에 이미 링크로 보인다. 접근성 요구가 인터랙션 문법을 만든 사례.

9. **포커스 링을 점선으로, 오프셋을 줘서 테두리와 분리해라.** `2px dashed #0057B8` + `offset 3px`, 어두운 밴드에서는 흰색 inverse. 실선 테두리를 가진 A–Z 칩에서도 점선 링이 3px 바깥에 따로 서기 때문에 묻히지 않는다. 포커스 토큰을 5개나 따로 둔 이유.

10. **스크림 그라디언트와 알파 사다리를 하나로 통일해라.** 히어로 오버레이와 위치 카드 6장이 `rgba(0,0,0,0) 27.4% → .56 58.85% → .8 100%` 하나를 공유하고, 재생 버튼의 rest/hover 배경이 그 두 정지점 알파(`.56`/`.8`)를 그대로 쓴다. 사진 위 텍스트 가독성 문제를 값 하나로 닫는다.

11. **duration 1개, easing 1개면 충분하다.** `0.3s` / `ease-in-out`, 토큰 두 줄. `transition: all` 사용 0건. 스크롤 리빌 0건, sticky 0개 — 5,407px를 내리는 동안 화면에서 움직이는 게 없다. 기관 사이트에서 모션의 정답은 대개 "없음"이다.

12. **대비를 4.5:1에 최대한 붙이되 넘기지 마라.** 11쌍 전수 AA 통과, 최저 4.81/4.83. 팔레트를 밝게 밀 수 있는 한계까지 밀고 멈춘 값이다. "여유 있게 통과"가 아니라 "정확히 통과"가 설계된 팔레트의 모습.

13. **사진은 적게, 종횡비는 2종으로.** 5,407px에 사진 7장. 에디토리얼 3:4 세로, 카드 4:3 가로, 그 외 없음. 자산이 적으니 촬영·검수·교체 비용이 낮고, 비율이 둘뿐이니 어느 자리에 무엇이 들어갈지 논쟁이 없다.

14. **홈의 4분의 1을 푸터에 줘라 — 기관 홈은 랜딩이 아니라 디렉터리다.** 기부(270) + 푸터 내비(853) + 법적(245) = 1,368px, 25.3%. 세리프 볼드 칼럼 헤더 9개(20px 7 + 16px 2) 아래 링크 리스트, 아이콘 박스 링크 3개, 법적 고지 8종. 방문자 대다수가 "예약"이 아니라 "내가 찾는 부서/문서"를 찾아 온다는 사실을 레이아웃이 인정하고 있다.

15. **신뢰 장치는 배지가 아니라 문장으로 넣어라.** 이 페이지에 수상 로고·인증 마크·숫자 카운터가 **하나도 없다**. 랭킹 주장은 본문 20px 한 줄로만 나온다 — `Mayo Clinic is the No. 1 hospital in the world according to Newsweek.` 그리고 바로 뒤에 근거로 가는 링크. **출처를 명시한 한 문장이 로고 배지 벽보다 기관답다.**

## 버릴 것

- **채운 버튼을 기부에만 주는 위계.** 비영리 병원이니까 성립한다. 상업 서비스가 이걸 흉내내면 주요 전환 경로를 스스로 아웃라인으로 낮추는 짓이다. 배울 것은 "예약을 약하게"가 아니라 **"채운 버튼은 페이지에 하나"**다.

- **`position: static` 헤더.** 5,407px를 내리는 동안 내비로 돌아갈 방법이 없다. 검색·예약 진입점도 함께 사라진다. 기관 사이트라 용인되는 것이지 좋은 선택이 아니다.

- **`#080808`과 `#000000`의 공존.** 본문은 `--mc-color-layer-tertiary-default(#080808)`인데 내비 라벨 5개만 순검정이다. 150개 노드짜리 페이지에서 니어블랙이 두 값인 건 토큰이 안 닿은 자리라는 뜻.

- **스타일 안 먹은 skip 링크.** `Skip to content`가 `rgb(0,0,238)` — 브라우저 기본 링크색이다. 포커스 토큰을 5개나 만든 사이트에서 접근성 진입점 하나가 소외됐다. Tab 실측에서도 이 요소만 `outline: auto 1px`(브라우저 기본)로 나온다.

- **이미지 11개 전부 width/height 속성 없음.** 526×701, 416×312를 속성 없이 던진다. `loading="lazy"`까지 전부 걸려 있어 CLS가 더 커진다.

- **`autoplay: true` + `muted: false`인 히어로 영상.** 이 조합은 대부분의 브라우저에서 자동재생이 차단된다. 포스터 이미지가 잘 만들어져 있어 티가 안 날 뿐이다.

- **AEM 컴포넌트 래퍼 비용.** 링크 라벨 하나를 그리는 데 `A > span.cmp-button__inner > span.__inner-wrapper > span.__inner-main > span.__text > span` **span 5겹**이 쌓인다. 가시 텍스트 노드 150개짜리 페이지의 DOM이 2,598개인 이유다. 토큰 시스템은 배끼되 이 마크업은 배끼지 마라.

### 스캐너 메모 (기록용)

- detect가 잡은 섹션 3개(header/nav/footer)는 **오탐이 아니라 한계**다. 본문 3,251px가 배경색 없는 단일 흰색 컨테이너(`aem-container`)라 배경 전환 기반 섹션 분할이 걸리지 않는다. 실제 섹션 경계는 사진 위치와 표제 y좌표로만 잡힌다.
- `TS3`("본문 스택이 기본값뿐: system-ui")는 **오탐**. `body`의 계산값은 `system-ui`가 맞지만 실제 텍스트는 전부 컴포넌트 레벨에서 `mayo-sans`/`mayo-display`/`mayo-serif`를 명시한다(요소 590개). toss가 `body { line-height: 16px }`로 상속을 죽인 것과 같은 패턴 — **상속을 안 쓰는 시스템에서는 body 계산값이 아무것도 말해주지 않는다.**
- `IC1`("동일 SVG 글리프 5·10회 반복")도 **오탐**. 셰브런 아이콘이 링크 리스트 전반에 반복되는 것이고 그리드 장식이 아니다.
- `LA3`("radius 1000px가 28개 중 27개 지배")는 미러 기준 수치. 라이브 실측은 1000px×58 / 8px×28로 **두 값이 공존**한다 — 필과 카드가 각자 역할을 갖는다.
