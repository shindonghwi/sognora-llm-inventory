# 판정 브리프 §E — 시안 대비 판정 (사용자가 고른 그림이 목표물)

- 근거: 담화 v2~v5 실전(2026-09-02~03) — 리드 사례를 그대로 옮긴 화면도, 모델이 발명한 화면도 거절됐고, 사용자가 고른 imagegen 시안을 전사한 화면만 타이포·구도 4점을 받았다. 판정 기준이 취향인 사용자에게는 코드 전에 그림이 필요하다.
- 실행: 블라인드 1인. 입력은 `board.png`(고른 시안) + 결과 캡처(데스크톱·모바일·필요 시 중간 상태). 시안이 있으면 compare의 자도 시안이다(리드 캡처 대신).
- 공통 꼬리말은 [ai-slop-judge](ai-slop-judge.md).

## 브리프

> 당신은 블라인드 판정자다. 아래 이미지들만 보고 판정한다. 제작 과정·의도·이전 판정은 모른다. 파일을 Read로 열어 보라.
>
> 목표물(사용자가 고른 디자인 시안): `<board.png>`
> 결과물 데스크톱 1440×900: `<desktop.png>` · 모바일 390×844: `<mobile.png>` · (있으면) 등장 중간 상태 · 중립 조명 진단.
>
> 먼저 목표물의 firstGaze/place/mood(세 단어), 그다음 결과물 데스크톱의 firstGaze/place/mood/subject(주 피사체를 이름 모른 채 명명, 재질도 명시)를 적어라.
>
> 축별 1~5점(5=목표물과 같은 밀도·완성도, 3 이하=그 층의 결함)과 이유 한 문장:
> match(시안 재현: 구도·비율·톤·요소 배치) / subject(피사체가 의도한 물체로 즉시 읽힘) / material(표면 재질이 무엇으로 읽히나) / medium(연기·빛·물 같은 매질: 밀도·결·소멸·색) / composition(시선 순서·여백·글자와 장면) / typography(크기·굵기·자간·위계가 목표물의 품질인가) / panel(패널·카드가 목표물처럼 읽히고 장면과 얽히는가) / mobile(재구도, 겹침·소실) / finish(잘림·겹침·계단·선예도 불일치) / parity(시안 옆에 두면 같은 사이트의 두 상태로 보이는가)
>
> 마지막으로 failingLayers(≤3 축 → 구도/형태/재질·빛/시간/입력/합성·렌더링/사용성/실행)와 가장 큰 차이 3가지("무엇이 어떻게 다른가", 수치로).
>
> 출력은 JSON 하나만.

## 통과선과 처분

- **parity ≥4 필수**, 전 축 ≥4. ≤3 = 그 층의 결함 → `defects.md`에 관찰·원인 층·수정·재검증 캡처를 적고 그 층만 고친다.
- 같은 층에서 세 번 연속 실패면 시안 단계로 올라가 방향을 다시 고른다. 피사체·시안은 사용자가 바꾸라고 하기 전까지 유지.
- 시안이 없는 페이지(내부 화면 등)는 이 브리프 대신 [ai-slop-judge](ai-slop-judge.md)·[sameness-judge](sameness-judge.md).
- 시안이 사진급이고 결과가 렌더면 "같은 브랜드의 두 페이지"까지는 되지만 "같은 사이트의 두 상태"는 어렵다(담화 v5 실측 parity 3). 그 격차가 기법의 한계면 보고서에 정직하게 쓰고 사용자에게 결정을 넘긴다.
