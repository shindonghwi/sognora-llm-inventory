# 방향 카탈로그 — 스킨 목록이 아니라 조합 축

- 근거 수준: 레퍼런스 실측(벤치마크 갭) + 실전 사고(모델 취향 수렴: 크림+괘선+좌측 에디토리얼).
- 판정자: 기계(scan 규칙 `palette.history-repeat`·`direction.axes-repeat`)(팔레트 계열 + 7축 중 3축), 기계(`conform.mjs` `token.*`)(토큰), 재생성 자기검증은 AD.

> **이 파일의 예시를 그대로 복사하면 위반이다.** 방향은 프로젝트 입력에서 유도(derivation)한다 — 입력이 다르면 산출이 달라야 정상이고, 같은 프로젝트를 재실행하면 같은 방향이 나와야 정상이다(입력 기반 = 재현 가능). 이 스킬이 "또 하나의 고정 스킨"을 찍어내는 순간 존재 이유가 사라진다.

## 시안이 먼저다

방향 유도는 **시안 2~3안을 만들기 위한 브리프**다. 사용자가 시안을 고르면 그 시안이 방향의 구체화이고, 축 기록은 시안에서 역으로 읽어 적는다. 시안 없이 축만 정하고 코드로 가는 것은 사용자가 "그냥 만들어"라고 했을 때만.

## 유도 절차 (계약의 방향 절에 근거와 함께 기록)

0. **히스토리 로드(하드 제약)**: `$SG_PAGE_FORGE_HOME/history.json`의 이전 실행을 읽는다. 이번 추첨은 **① 베이스 팔레트 계열이 마지막 실행과 달라야 하고**(검수에서 baseHex 대조 — 크림을 썼으면 크림·베이지·웜오프화이트 전 계열 배제) **② 7축 중 3축 이상이 마지막 실행과 달라야** 한다. 이 제약이 "매번 같은 형태"를 막는 본체다.
1. **입력 수집**: ① 콘텐츠 도메인 ② 기존 브랜드 자산(로고 색, 이미 쓰는 폰트, 일러스트 톤 — 방향의 씨앗, 교체 대상 아님) ③ 격식도(B2B 공구·의료 = 높음, 커뮤니티·라이프스타일 = 낮음) ④ 사용자 명시 취향(최우선)
2. **반프로필 확정**: 배제 목록 = 원본 슬롭이 쓴 계열 + AI 공식(보라-남보라 그라데이션, 유리morphism, Inter 단독) + **AI 수렴 룩 세대들**(2026: 크림+고대비 세리프+테라코타 / near-black+애시드 그린·버밀리언 / 브로드시트 헤어라인·radius 0 — 유통기한 있음, 벤치마크 실측에서 갱신) + 직전 실행 조합. **금지가 아니다** — 브리프가 명시 요구하면 쓴다. 죄는 빈 축을 이 기본값으로 채우는 것.
3. **축별 선택**: 7축에서 입력에 근거해 하나씩. 근거 없는 축은 도메인 관례에서 유도하고 "관례 유도" 표기. 확정 직전 **재생성 자기검증**("비슷한 브리프에 또 나올 조합이면 기본값이다").
4. **구체화**: 축 조합을 실제 토큰(폰트 이름, hex 팔레트, 스케일 비율, radius 위계)으로. **팔레트와 타입 페어링은 ①②의 입력값에서 계산** — 예시 hex를 옮겨 적지 않는다.

## 7축

### 1. 타이포 보이스
- 그로테스크 단정(정보 밀도 높은 도구) · 세리프 에디토리얼(신뢰·읽을거리) · 라운드 산세리프(친근·생활) · 좁은 폭 디스플레이(임팩트) · 모노 포인트(기술 정체성)
- 대비는 무게보다 서체·크기·자간으로 먼저([typography](systems/typography.md) 300~600 창). 극단 무게 대비(100–200 vs 800–900)·3배 이상 사이즈 점프는 **시그니처로 선언할 때**의 선택지. 타입 트리트먼트 자체가 기억점이어야지 중립적 배달 수단이면 실패.
- **한글 제약(항상)**: 이탤릭 금지, 본문 행간 1.6~1.8, 자간 0~미세 음수, 헤드라인·본문 모두 한글 대응 폰트 명시, 라틴은 x-height가 맞는 것으로 페어링. 폰트 선택은 코딩 전에 선언.

### 2. 컬러 전략 — [color](systems/color.md)
단색 지배 + 예리한 강조 1색 · 어스톤 · 고대비 흑백 + 유채 1점 · 저채도 2색 · 딥톤 배경 + 밝은 전경. 강조색은 브랜드 hue 또는 도메인에서 유도. 그라데이션은 명시 채택 시 페이지 1곳.

### 3. 레이아웃 문법
비대칭 2단(본문 우세) · 에디토리얼 세로 흐름(섹션 경계를 타이포로) · 신문형 밀집 그리드 · 풀블리드 미디어 교차 · 좌측 정렬 통일. 카드 3장 한 줄·중앙 히어로는 반프로필 기본 배제 — 채택하려면 근거.

### 4. 밀도 자세
밀집 · 중립 · 성긴 여백(콘텐츠가 실제로 받쳐줄 때만 — 여백은 콘텐츠 부족의 변명이 못 된다, `density.void-band`).

### 5. 장식 언어
무장식 · 기하 도형 1종 · 실사진 · 손그림/일러스트 · 괘선 중심. **한 언어로 통일**, 아이콘 세트도 1세트.

### 6. 모션 자세 — [motion](systems/motion.md)
정적 · 진입 1회(1패턴만) · 포인트 모션(핵심 1~2곳). infinite 루프 장식 금지(`motion.infinite-loop`). 프리셋 6종 밖을 새로 짜지 않는다.

### 7. 시그니처 (필수 — 방향의 마침표)
**이 화면이 기억될 단 하나의 요소**를 이름 붙여 선언한다. 대담함은 여기에만. 시그니처 없는 방향은 미완성이다.

## 기록 양식 (계약의 방향 절)

`
방향: <7축 선택 요약 이름 — 직접 명명>
시안: <고른 시안 파일> (없으면 "사용자 지시로 생략")
입력: 도메인=… / 브랜드 자산=… / 격식=… / 사용자 취향=… / 벤치마크 갭=<벌어진 축 순위>
반프로필: <배제한 계열과 이유>
축: 타이포=…(근거) / 컬러=…(근거) / 레이아웃=…(근거) / 밀도=…(근거) / 장식=…(근거) / 모션=…(근거) / 시그니처=…(단 하나, 근거)
토큰: 폰트=<한글 폰트+페어링> / 팔레트=<유도된 hex 5±2> / 스케일=<기준px·비율·단수> / radius=<위계> / 간격=<기준 단위>
