# 유형 — 문서 `document` (읽는다 → 조건을 확인한다)

- 근거 수준: 실전 사고(정책 4종이 한 틀 — 정상) + 구조 밀도 실측.
- 판정자: 기계(scan 규칙 `document.no-header`·`document.no-toc`·`copy.*`; 교차 `sameness.*` — 같은 유형끼리 100% 일치는 **정상**). `structure.prose-only`는 **적용하지 않는다**(privacy 실측 0.88 — 글이 본체).

## 동사와 필수 구조

| 항목 | 값 |
|---|---|
| 사용자 동사 | 읽는다(조건을 확인한다) |
| 필수 구조 | 시행일·문의처 + 목차 + 번호 붙은 절 |
| 해당 | 정책·약관·이용정책·환불·개인정보 전부 |
| 소개문으로 열어도 되나 | ✅ |
| 일 점유율 실측 | 본문 절 23~25% — 이 값이 하는 화면 `work.starved`의 자(중앙값)가 된다 |

## 규칙

- 같은 렌더러에서 나온 문서 4종 = 골격 100% 일치(6쌍 전부)는 옳다. 유형마다 화면을 새로 발명하는 것이 오히려 표류.
- 시행일·문의처가 상단에 있어야 `document.no-header`를 피한다. 절 번호와 목차 앵커가 구조 요소다.
- 카피: 문장 25단어·문단 5문장·제목 65자(기계(scan 규칙 `copy.length`, GOV.UK 콘텐츠 가이드)).
