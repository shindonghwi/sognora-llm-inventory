# 유형 — 랜딩 `landing` (읽는다 → 설득당한다)

- 근거 수준: 실측(레퍼런스 라이브러리 IR 19종·코퍼스 보정) + 실전 사고 기록. 근거 없는 항목은 끝의 "관행" 절에만.
- 판정자: 기계(scan)(AI 티·밀도·한글·품질 바닥) · 기계(scan 규칙 `skeleton.vs-ir`·`scene.repeat-run`·`depth.vs-lead`) · 기계(`behavior.mjs` `motion.engineered-floor`·`motion.nojs-visible`·`motion.reduced-safe`)(엔지니어드 모먼트) · 기계(`conform.mjs` `token.*`)(토큰) · 판정 브리프 [ai-slop-judge](../judge/ai-slop-judge.md)·[desire-judge](../judge/desire-judge.md)·[persona-judge](../judge/persona-judge.md)·[gatekeeper-judge](../judge/gatekeeper-judge.md).

## 동사와 필수 구조

| 항목 | 값 |
|---|---|
| 사용자 동사 | 읽는다(설득당한다) |
| 필수 구조 | 히어로 · 증거 · CTA |
| 소개문으로 열어도 되나 | ✅ (읽는 화면) |
| 블록 간 세로 간격 중앙값 | 96~120px — 리듬이 상품이다, 스크롤이 서사([spacing](../systems/spacing.md)) |
| 밀도 판정 | 사람(AD 검수). 자동 측정은 DOM 깊이에 흔들려 버렸다 |

## 히어로 — 결과를 판다

- **중심 장면 1개 의무** — contract에 "이 페이지의 중심 장면"을 한 문장으로 정의한다(예: "제품 링크를 넣자 검색·이미지·영상 광고가 한꺼번에 완성되는 장면"). 사용자가 해야 할 입력 작업("~을 등록하세요")을 파는 히어로 금지, CTA도 결과 언어(형식: "무료로 <제품의 산출물> 만들기/받기"). 판정: [persona-judge](../judge/persona-judge.md) ②·[desire-judge](../judge/desire-judge.md).
- **첫 화면 산출물 하한** — 히어로에 제품의 완성 산출물이 최소 1점, 산출물 다양성이 핵심 가치면 다수(벽 형태)가 실물로 보여야 한다. 큰 글씨+CTA만 있는 히어로, 절차도·스테퍼가 첫 스크롤의 주인공인 히어로는 실패(실측 대조: 경쟁 76점 히어로엔 생성 결과 4장+컨셉 4개가 떠 있고, 44점 히어로엔 흰 배경에 큰 글씨만). 미도장·미완성 "입력물" 사진도 같은 실패 — **히어로는 애프터를 판다.**
- **디스플레이 모먼트** — 히어로 헤드라인 ≥ 본문 4배(라이브러리 실측 4.1~7.2×). [typography](../systems/typography.md)
- **면책·부정 고지** — 페이지 전체 1회, 히어로에 두지 않는다. "아직 제공하지 않습니다"류도 정직 고지 자리 1곳으로.

## 카피 시점 — 제작 노트도, 설명서도 아니다 (판정: 기계(scan) `copy.maker-voice`·`copy.manual-voice` + 카피 검수 + 페르소나)

실전 사고: 본문에 "셀프 촬영·사용 장면·제품 시연을 짧게 이어 붙였습니다. 자막과 버튼은 실제 피드에서 잘리지 않는 자리에 놓았습니다"가 실렸다. 만든 사람이 자기가 한 일을 보고하는 문장이고 방문자에게는 값어치가 없다.

- **제작자 시점 금지(`copy.maker-voice`·🔴)** — "이어 붙였습니다·배치했습니다·놓았습니다·구성했습니다·반영했습니다·촬영했습니다". 제작 방식·규격 준수·내부 판단은 보고서에 쓰고 페이지에 쓰지 않는다.
- **설명서 시점 금지(`copy.manual-voice`·🔴)** — "~하시면 됩니다·입력하세요·먼저 ~한 뒤·다음 단계"로 절차를 가르치는 문장이 본문을 지배하면 매뉴얼이다.
- **카피는 고객 시점의 결과** — 주어는 고객 또는 산출물. 검증: 문장 앞에 "우리가"를 붙여 자연스러우면 제작 노트, "당신은"을 붙여 자연스러우면 카피.
- 내부 메모(트레이드오프·미구현 사유·향후 계획)는 페이지에 싣지 않는다.
- 모든 주장·수치가 facts의 출처와 1:1 — 대응 없는 문장은 삭제. 제품이 안 하는 것(로드맵·미출시)을 하는 것처럼 쓰기 금지.
- 한·영 카피 알려진 🔴 패턴 0 — 렌더 카피를 한·영 카피 패턴 판정기(장르 landing)에 파이프. exit 1이면 실패. exit 0은 자연스러움의 증명이 아니다.

## 시각 앵커·콘텐츠 예산 (판정: 기계(scan) `icon.numbered-list`·`density.*` + 카피 검수 + AD)

실전 사고 근거: 번호 텍스트 목록 카드("01 건물의 주요 외벽"), 서술형 스탯 밴드("첫 작업 과정 검토 중"), 여백으로 부풀린 얇은 섹션.

- **시각 실체는 이미지로 말한다** — 대상이 물리적 실체(건물·제품·공간·산출물)면 그 실체의 이미지(E/P/I 경로, [assets](../systems/assets.md)) 위에 주석·오버레이로 설명한다. "01/02/03" 텍스트 목록 대체 금지 → **`icon.numbered-list`(🔴)** 기계 검출(세로 목록·가로 스테퍼 양축, "STEP 01"·"단계 1" 포함). 레퍼런스 실측: jobber 업자 얼굴 26장, airbnb 사진 카드, hyundai 풀블리드 — 실체를 텍스트로 설명하는 사례 0.
- **스탯·상태 밴드는 측정값만** — 숫자·날짜·고유명사가 없으면 밴드를 생략한다. "검토 중"·"진행 중" 서술문은 스탯 자리 금지 → **`density.prose-stat-band`(🔴 혐의)**.
- **콘텐츠 예산** — 섹션 수는 facts 재고에 종속. 말할 것이 없으면 섹션을 줄인다. 여백+얇은 텍스트로 부풀리면 `density.void-section`·`density.sparse-card-row`·`density.void-band`. AD는 계약에서 "facts N개 → 섹션 M개"를 명시.
- **깊이 하한(반대 방향)** — "정직하게 짧은 페이지"는 facts 조사가 얕았다는 핑계가 못 된다. ⓐ facts에 **제품 인벤토리 절 의무**(제품 화면 전수·플로우 단계·산출물 유형과 실규격·프로세스/권한/비용) ⓑ **리드 대비 깊이 대조(기계, scan 규칙 `depth.vs-lead`)** — 스크롤 길이·섹션 수를 리드 IR과 비교, **−40% 초과 축소는 mapping에 섹션별 삭제 사유 전수 기재**돼야 통과.
- **깊이의 단위는 절차가 아니라 장면(매뉴얼화 금지)** — 실전 사고: 깊이 하한을 절차 설명으로 채움 → "가입 전에 읽는 매뉴얼"(매력 44/100). 사용 절차·규격·권한은 압축 모듈 1~2개, 깊이는 갖고 싶은 산출물·증거·장면의 다양성으로. 절차 섹션이 산출물 섹션보다 많으면 매뉴얼.
- **동어반복 금지(카피×아이콘)** — 항목 제목이 같은 어미·같은 명사로 끝나는 나열("보여 주는 기능 / 읽는 기능 / 준비하는 기능")은 위반, 옆에 제네릭 시스템 아이콘 세트를 붙이면 이중 위반. 같은 아이콘을 다른 섹션에서 재사용 금지.
- **반폭 공백 금지** — 카드·밴드에서 콘텐츠가 좌측 절반만 쓰고 우측이 비면 위반(실측: 폭 1270 CTA 카드에서 우측 435px 공백).
- **세로 공백 지배 금지(`density.void-band`·🔴)** — [spacing](../systems/spacing.md) 참조. 처방은 패딩 축소가 아니라 내용 투입.
- **히어로 카피 복제 금지** — 최종 CTA가 히어로 헤드라인·라벨을 어미까지 되풀이하면 위반.
- **번호 체계 단일화** — 페이지 내 단계 번호는 한 체계(02가 두 번 등장 사고).
- **소재는 산출물이 아니다** — 스톡·생성 제품 사진 스트립은 산출물 전시가 아니며 갤러리 다양성 계수에도 안 든다. 산출물로 인정되려면 실제 게재 크롬(광고 배지·도메인·CTA·플랫폼 UI)이 붙어야 한다.
- **장면 예산** — 같은 배경·같은 레이아웃 시그니처가 **연속 3섹션 이상**이면 위반(기계(scan 규칙 `scene.repeat-run`)). "9,500px 내내 같은 화면" 사고의 방어선.
- **정직 고지는 1곳에 집약** — "베타"·"준비 중" 반복 금지. 전용 자리 1곳.
- **산출물 리얼리즘** — 제품 결과물은 실제 게재 매체의 실규격·실UI 안에 조립(검색 광고는 검색 결과 UI, 배너는 IAB 300×250 등). 문구를 이미지에 굽지 않는다 — 텍스트·UI는 HTML/CSS, 이미지 생성은 사진 소재까지만. 판정: [gatekeeper-judge](../judge/gatekeeper-judge.md) 목업 진위감.
- **아이콘 양방향** — 의미 결합 없는 장식 아이콘 금지(`icon.decorative`). 그러나 라벨·카테고리·리스트에 시각 앵커 0인 텍스트 벽도 금지 — 아이콘 세트가 정답(실측: mayoclinic 191개 체계, toss 다색 4x PNG). 제작 규격은 [assets](../systems/assets.md).

## 퀄리티 바 — 완성선 (보고서에 항별 근거)

1. 디스플레이 모먼트 — 헤드라인 ≥ 본문 4배
2. 한 화면 동시 위계 ≤ 6단(총 단 수보다 이게 실제 규칙 — toss 실측)
3. 자산 플랜 이행 — 계획 파일 목록과 배치 일치, 재사용 0
4. 색 커밋 — 지배 1 + 강조 1이 전 섹션 관통
5. 빈 공간은 의도일 때만 — 실증으로 채우거나 섹션을 접는다
6. 차용 이행 — provenance(transform ledger)의 각 항목이 구현에 반영됐는지 대조

## 같은 형태 반복 금지 (판정: 기계(scan 규칙 `palette.history-repeat`·`direction.axes-repeat`))

`$SG_PAGE_FORGE_HOME/history.json`의 마지막 실행과 **베이스 팔레트 계열 상이**(scan 규칙 `palette.history-repeat` — `page.bodyBg`로 대조) + **7축 중 3축 이상 상이**([directions](../directions.md)). 완료 시 append. 반복 금지는 프로젝트를 가로지르는 제약이라 프로젝트가 아니라 스킬 홈이 기억한다.

**리드 회전**: history에 `lead` 기록. 동일 리드는 최근 3회 내 재사용 금지(사용자 지명 예외). 변환에서 리드는 다양성의 제1축이다.

## 랜딩 표류 (다른 유형이 이 구조로 흘러드는 것)

카탈로그·도구·요금제·폼·대시보드에 후기·가격 밴드·CTA 밴드가 들어가면 기계(scan) **`type.landing-drift`** — 단어가 아니라 섹션 실체로 판정(인용 블록 2개+ / testimonial 클래스 블록 h≥120 / 가격+주기 패턴). 유형 목록에 없는 화면은 랜딩으로 회귀하지 말고 `read:<라벨>`·`do:<라벨>`로 동사를 선언한다.

## 방향 면제 (스타일 채택 조항)

잘 만든 사이트도 티를 갖는다(meshy 실측: 🔴 8개인데 산출물 109개가 전부 정당화). **기본값으로 소비가 죄이지 선택은 죄가 아니다.** AD가 `exemptions.md`에 **룰 ID + 채택 사유 + 정당화 조건**을 선언하면 검수에서 "채택된 스타일"로 보고한다. **면제 불가**: 규칙 색인의 "면제 불가" 표시 규칙(`quality.*`·`text.hidden-at-rest`·`type.min-size`·`page.blank`·`korean.line-height`·`korean.italic`·`font.hangul-fallback`·`asset.placeholder`·`copy.maker-voice`) — 스타일이 아니라 결함이다.placeholder`, 가짜 증거. 정당화 조건 미충족 시 면제 무효(갤러리 없는 다크 시네마는 빈 어둠).
