# 유형 — 대시보드·목록·상세·설정 `dashboard` (본다·관리한다)

- 근거 수준: 실전 사고(계정 6종 "규격화된 AI 템플릿 느낌" — 계기 전부 초록이었던 사건) + NN/G 상태 화면 지침 + Spectrum·Carbon·Primer 토큰.
- 판정자: 기계(scan 규칙 `dashboard.thin`·`state.empty-missing`(경고)·`work.starved`(🔴)·`sameness.flat-density`(🟡)·`component.*`·AI 티 규칙 전수).

## 동사와 필수 구조

| 항목 | 값 |
|---|---|
| 사용자 동사 | 본다·관리한다 |
| 필수 구조 | 반복 데이터 + 상태 화면 |
| 소개문으로 열어도 되나 | ❌ |
| 블록 간 세로 간격 | **16~32px** — Carbon 행 높이 xs 24 / sm 32 / md 40 |

## 일 점유율 — 그 일이 첫 화면의 주인공인가 (판정: `work.starved`)

실측(1440×900, 주 행위 요소의 첫 화면 면적 점유율):

| 화면 | 유형 | 주 행위 요소 | 점유율 |
|---|---|---|---|
| `/product` | 카탈로그 | 카드 격자 | 69% |
| `/app/account/credits` | 대시보드 | 입력 폼 | 65% |
| `/app/account/profile` | 대시보드 | 입력 폼 | 62% |
| `/contact` | 폼 | 입력 폼 | 59% |
| `/terms`·`/privacy` | 문서(읽는다) | 본문 절 | 25% · 23% |
| `/app/account` | 대시보드 | 행 목록 | **20%** 🔴 |
| `/app/account/billing` | 대시보드 | 표 | **15%** 🔴 |
| `/app/account/security` | 대시보드 | 행 목록 | **11%** 🔴 |

**23%와 59% 사이가 비어 있다.** 굶은 세 화면은 읽는 화면(정책 문서)보다도 일이 화면을 덜 덮는다. 나머지 80~90%는 제목·라벨·설명·여백 — 이것이 "AI 템플릿 느낌"의 관측 가능한 형태다. 닮음 축으로는 못 잡는다(각자 다른 모양으로 헐거울 수 있다).

- **임계는 자가 보정** — 그 프로젝트 **읽는 화면들의 본문 점유율 중앙값**이 자. 엄격해지는 방향으로만(폴백 25% 하한). 읽는 화면이 없으면 폴백을 쓴다고 보고서에 밝힌다. **1장만 검사할 때도 읽는 화면 1~2장을 같이 넣어라.**
- **처방은 패딩 축소 금지** — 실체를 넣어 비율을 올린다.
- **빈 상태 주의** — 데이터 0건과 설계 헐거움을 기계는 구분 못 한다. 골격 블록 2개 미만이면 "빈 상태면 데이터를 넣고 다시 재라".
- 남는 면적이 글인지 여백인지 잰 값으로 갈라 적는다(잉크율 > 점유율 → 소개문 제거 / 아니면 → 실체 투입).

## 상태 커버리지 (이 유형에서 새로 재는 유일한 것)

- **빈 상태** — 목록·표마다 0건 화면이 있는가, 그 화면에 **다음 행동**이 있는가("No data found"만 있으면 미달)
- **로딩** — 스피너 하나로 때우지 않았는가(구역별 스켈레톤), **실은 로딩인데 빈 상태를 먼저 보여주지 않는가**(NN/G "특히 해롭다")
- **오류·권한 없음** — 존재하는가, 원시 에러 메시지를 노출하지 않는가
- **상호작용 상태** — hover·active·focus가 실제로 다른가
- **실데이터 내성** — 긴 이름·대문자 약어·0건·1건·많은 건수에서 레이아웃이 버티는가

기계(scan)가 빈 상태 분기 부재를 경고한다. 나머지는 사람이 화면을 열어 확인한다.

## 제품 화면에서 살아남는 AI 티 (근거: Design Slop Cop 1,590개·impeccable.style/slop 64패턴·CHI EA 2026)

- **상태 부재** — 가장 가치 높은 신호
- **균질성** — 간격 한 값, 카드 높이·라운드·패딩 전면 동일, 타입 계층 평탄(비율 1.25 미만), 모든 액션 같은 무게, 화면마다 다른 라운드·폰트
- **표면 처리** — 카드 속 카드, 좌측 액센트 스트라이프, 헤어라인 보더+넓은 그림자 동시, 작은 카드 radius 24px+, 채도 글로우, 손 안 댄 `rounded-2xl shadow-lg p-6`
- **아이콘·카피** — 내비 이모지(링크 3개 이상 중 40% 초과 — 단일 지표로 가장 강함), Lucide 5종(Sparkles·Zap·Shield·Check·BarChart3)+모든 CTA에 ArrowRight, ✦ 반짝이(NN/G n=107에서 "AI"로 읽은 사람 0명), 동어반복 라벨, 전면 Title Case
- **가짜 데이터** — "10K+ users"·"99.9% uptime" 정적 마크업, `Acme Corp`·`John Doe`·`Item 1/2/3`, 하드코딩 위의 맥동 상태 점, 모든 지표에 같은 초록 상승 화살표
- **모션**(Emil Kowalski) — `transition: all`, 진입 `ease-in`, `scale(0)` 진입, 300ms 초과, 진입·퇴장 속도 동일, `(hover: hover)` 가드 없는 hover → [motion](../systems/motion.md)
