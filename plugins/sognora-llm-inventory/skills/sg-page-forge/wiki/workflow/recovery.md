# P7 — 복구: 폐기 대신 층

> 판정자: `lint-docs.mjs`(defects.md 열·재검증 캡처·폐기 인용) · 재검증은 같은 상태의 audit/캡처.

## defects.md

| # | 관찰(캡처) | 근거 | 원인 층 | 수정 | 재검증 | 상태 |
|---|---|---|---|---|---|---|

- 원인 층: 목적 / 구도 / 형태 / 재질·빛 / 시간 / 입력 / 합성·렌더링 / 사용성 / 실행 / 콘텐츠 / 카피.
- "해결"에는 같은 상태의 재검증 캡처 파일명(뷰포트 포함)이 있어야 한다. 없으면 "미검증".
- 전체 폐기는 사용자 문장을 인용해야 lint가 받는다. 스킬이 스스로 갈아엎지 않는다.

## 결함이 말하는 것 → 돌아갈 페이즈

| 결함 | 층 | 페이즈 |
|---|---|---|
| "이 페이지는 무엇을 하는 곳인가"가 안 읽힘, 랜딩으로 회귀 | 목적 | P0 계약(유형·동사 재선언) |
| 시안과 다른 구도, 시선이 갈 곳 없음, 빈 띠 | 구도 | P3 전사(시안 실측표 재작성) |
| 글만 있는 페이지, 컴포넌트 없음 | 콘텐츠 | P0 facts 보강 → P5 |
| AI 티 ≤3 섹션 | 구도·콘텐츠 | **철거 후 재단조** — 치환 전략 1축 교체(시각 앵커/graft/카피 각도). 수리 금지. 2연속 철거면 그 섹션은 정직하게 생략 |
| 매력 미달 | 목적 | P2 시안 재선택(중심 장면·방향 재설계) |
| 토큰 위반, 잔존, 정적 페이지 | 실행 | P5 |
| 페이지끼리 같은 틀(CROSS-TYPE-CLONE), 하는 화면이 소개문으로 염 | 구도 | P3(그 유형의 브리프 재작성) |
| 폰트 폴백·굵기·자간(`font.*`·`type.*`·`korean.*`) | 재질 | P3 토큰 |

같은 층에서 세 번 연속 실패하면 P2로 올라가 시안을 다시 고른다. 피사체·방향은 사용자가 바꾸라고 하기 전까지 유지한다.

## 후속 명령

- "이 섹션만 다시" — 그 브리프부터 P5~P6.
- "방향 바꿔" — history에 현재 방향을 반프로필로 추가하고 P2부터.
- "리드 바꿔" — P1부터.
- "사진 왔어" — 슬롯 교체 후 P6.
- "진단만" — verify `--diagnose`, 재제작 없음.

## 완료 보고

리드와 근거 수준, 고른 시안, 캡처 위치, audit 결과(미제공 포함), 시안 대비 축별 점수, 패널 점수, 남은 🟡와 이유, 숙제(촬영·자료). 마지막에 `node "$S/history.mjs" append --lead <이름>`으로 이력을 남긴다(다음 실행의 반복 금지 축이 여기서 판정된다). 테스트 PASS·코드 줄 수·위키 개편은 품질 증거가 아니다.
