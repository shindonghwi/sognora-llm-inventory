# 시스템 — 자산 (증거·제품 화면·설명 소재)

- 근거 수준: 레퍼런스 라이브러리 실측(SVG 정책·성능 예산 jobber 169KB), 실전 사고(무라벨 생성 소재·동일 시안 반복), meshy 실측(고유 산출물 109개).
- 판정자: 기계(scan) `asset.reuse`(동일 이미지 3회+)·`asset.placeholder`(플레이스홀더) · [gatekeeper-judge](../judge/gatekeeper-judge.md)(인슬롯 렌더 캡처로 실물감·무라벨·핏·전후 일관성·시장 정합·목업 진위감·중복) · 자산 등급 = 페이지 등급 상한.

## 3클래스 — 허용 경로와 등급 캡

| 클래스 | 정의 | 허용 경로 | 금지 |
|---|---|---|---|
| **E (증거)** | 고객·작업자 얼굴, 후기, 별점, 현장 실적 사진, 사용 수치 | **수집만** — 실물 제공·촬영 | 생성·연출·스톡 대체 **절대 금지**(가짜 증거 = 최악의 사고, 등급 D) |
| **P (제품 화면)** | 앱·UI 스크린샷 | **픽스처 시딩 후 실캡처** — 현실적 데이터(항목 3~4건·현지 명명·날짜·상태) | 생성 목업, 빈 껍데기 |
| **I (설명·환경)** | 다이어그램, 색상 시트, 질감, 환경·건물 사진, 예시 산출물 갤러리("예시" 정직 라벨) | 직접 제작·생성(imagegen)·정식 라이선스 스톡 | 시장 불일치 소재(한국 시장에 미국 주택) |

**등급 캡**: E 부재 시 페이지 상한 B — 슬롯을 정직하게 생략하고 `homework.md`(샷리스트)를 발행, 보고서에 캡 사유.

## 생성 소재 규칙

- **무라벨 금지** — 제품·브랜드가 등장하는 소재에 라벨·마크가 없으면 실패(무라벨 병·캔·마크 없는 기기는 생성 이미지의 서명). 가상 브랜드라도 이름·로고를 붙여 생성하거나 후처리 합성. 소재 색이 페이지 브랜드색과 정확히 일치하는 것도 프롬프트 흔적.
- **동일 시안 반복 금지** — 같은 산출물이 두 섹션 이상에 그대로 재등장하면 위반. 단계별 연속성은 같은 캠페인의 다른 변형으로.
- **갤러리 다양성** — 서로 다른 피사체·업종 ≥4(한 사례 리사이즈 돌려쓰기 금지).
- **소재는 산출물이 아니다** — 실제 게재 크롬이 붙어야 산출물([landing](../types/landing.md)).

## 슬롯 우선 (생성 자산 공통)

- 모든 생성·크롭·캡처는 **슬롯 명세**(렌더 치수 데스크톱·모바일, 종횡비, object-fit, 라운드, 주변 배경 hex, 투명 여부, 오버레이 안전영역)를 읽고 시작. 명세는 **리드 IR의 실측 슬롯에서 자동 도출**. 없으면 생성하지 않고 AD에 보완 요구.
- 생성 해상도 = 슬롯 ×2(레티나), 종횡비 고정, 프롬프트에 종횡비·구도 명시. 오버레이 슬롯은 텍스트 방향 구도를 비운다.
- **인슬롯 핏 검증 루프**: ① 레터박스·여백 땜빵 0 ② object-fit 크롭이 피사체 훼손 없음 ③ 모바일에서도 ①② ④ 배경색·조명 정합. **3회 실패면 슬롯이 문제** → AD에 슬롯 재설계 콜백.
- 판정 입력은 원본이 아니라 **인슬롯 렌더 캡처**.

## imagegen 경로

Codex 내장 `imagegen` 스킬(이름은 imagen이 아니라 **imagegen**) — `comp.mjs`와 같은 `codex exec` 파이프 경로. codex CLI가 없는 환경에서는 프롬프트 파일만 남기고 그 자산을 "미제공"으로 보고한다 — 사용자가 다른 생성기로 만든 파일을 슬롯에 두면 이어진다. SVG 즉석 작도로 때우지 않는다. 프롬프트 전문을 `<이름>.prompt.md`에 남긴다.

아이콘: 투명 생성(세트 전체 단일 스타일 프롬프트) → 배경 잔여 제거 → 여백 트림(`magick -trim +repage`, ImageMagick 없으면 python Pillow `Image.getbbox()`) → 캔버스 정규화 → 토큰 색 결합 → **인슬롯 렌더 확인**. E클래스 생성 절대 금지, P클래스는 픽스처 시딩 후 실캡처만.

## SVG 정책 (레퍼런스 라이브러리 실측)

레퍼런스에서 SVG의 용도는 셋뿐 — ① 전문 아이콘 세트(단순 기하) ② 로고 ③ 초소형 기능 자산(마스크·호버 밑줄·괘선, jobber rip.svg처럼 단일 path). **일러스트·다이어그램·시트·건물·사람·제품 그림을 SVG 좌표로 즉석 작도하는 것은 금지** — 라이브러리 전수에서 0건(toss는 다색 아이콘조차 4x PNG, airbnb 일러스트는 PNG 3D 렌더). LLM은 시각 피드백 없이 좌표를 산수로 찍으므로 반드시 어색하다. 허용된 마이크로 SVG도 렌더→눈 확인 루프 필수.

## 산출물 리얼리즘

제품 결과물은 실제 게재 매체의 실규격·실UI 안에 조립(검색 광고 → 검색 결과 UI, 배너 → IAB 300×250, 문서 → 실제 뷰어 프레임). **문구를 이미지에 굽지 않는다** — 텍스트·UI는 HTML/CSS, 이미지 생성은 사진 소재까지만.

## 성능 예산

히어로 자산 ≤200KB(webp), LCP 대상 명시, 이미지 width/height(CLS는 Lighthouse 관할). og:image·파비콘·공유 카드는 자산 스프린트 산출물.
