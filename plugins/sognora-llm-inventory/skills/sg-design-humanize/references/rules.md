# sg-design-humanize — 룰북 (SSOT)

> Claude Code·Codex 양쪽이 공유하는 본체. 내용 수정은 이 파일에서만 한다.
> 룰 ID는 `scripts/rules-lib.mjs`와 1:1 대응 — 한쪽만 고치면 게이트가 어긋난다.

표기 —
- 심각도는 **"누가 알아보는가"로 나눈다** (짜증의 크기가 아니라): 🔴 **일반 사용자도 알아봄** — 즉시 수술 / 🟡 **디자이너·개발자가 알아봄** — 반복·결합 시 수술 / ⚪ **장인정신·마감 격차** — 개편 모드에서만. 맥락이 티어를 올리고 내린다(중앙 히어로는 제네릭 SaaS에선 🔴, 럭셔리 문법에선 무죄). 예외: 접근성 결함(:focus-visible 누락 등)은 티어 무관 우선.
- 층위: **[구조성]** 레이아웃 스켈레톤을 갈아야 사라짐 / **[표면성]** 토큰(폰트·색·radius) 교체로 사라짐
- 판정: **[결정적]** 스크립트 판정이 최종 / **[혐의]** 스크립트는 후보만 올리고, 승격/기각은 LLM이 감사 로그에 사유와 함께 확정

## 건드리지 않는 것 (Do-NOT)

본문 텍스트·링크(앵커텍스트+href)·정보성 이미지·폼 동작·라우팅·a11y 속성. 기존 브랜드 자산(로고·브랜드 폰트·브랜드 컬러)은 교체 대상이 아니라 방향 유도의 **입력**이다. surgical 모드에서는 프로젝트 디자인 시스템의 토큰 이름 체계도 보존한다(값 조정은 가능).

**슬롭이 아닌 것 — 오탐 억제.** 다음은 티로 취급하지 않는다: ① 의도가 분명하고 방향과 정합하는 대담한 선택 ② 주석·`direction.md`·프로젝트 디자인 시스템 문서에 근거가 기록된 의도적 이탈 ③ (기본 모드에서) 이번 작업 범위 밖의 기존 코드 ④ 린터·포매터 소관(따옴표·임포트 순서 등) ⑤ **의도적 예시** — `examples/`·`fixtures/`·`__mocks__/`·`stories/` 경로이거나 slop-example 류 명시 표식이 있는 코드(AI 패턴을 *다루는* 데모·교육 예제). 면제는 이 열거 신호가 있을 때만. **확신이 안 서면 결함이 아니라 결정으로 취급한다.** 클리셰 룩도 금지가 아니다 — 브리프가 명시 요구하면 쓴다. 죄는 "선택"이 아니라 "기본값으로 소비하는 것"이다. 그리고 **깨끗한 감사도 유효한 결과다** — 이미 의도적인 UI에는 그렇게 말하고 멈춘다(문제를 제조하지 않는다).

## 과잉 수술 가드

- **무티 섹션 면책**: 티 0인 섹션은 기본 모드에서 불가침. 개편 모드에서도 토큰(타입 스케일·팔레트·간격)만 새 방향으로 통일하고 구조는 보존 — 보고서에 "구조 보존: N개 섹션(사유: 티 없음)"으로 선언한다.
- **조기 종료 (티 제거 모드 전용)**: before 스캔에서 확정 티 0이면 퀄리티 바 약식 평가 후 종료한다 — 미달 항목이 있으면 "개편 모드 권장"을 반드시 고지한다(허접한 페이지에 "이미 좋습니다"를 말하지 않는다). **개편 모드는 티 0이어도 종료하지 않는다** — 완료 조건이 퀄리티 바이기 때문이다.
- **콘텐츠 부족은 디자인으로 못 감춘다**: 밀도 처방(§6)이 전부 불가하면 장식으로 채우지 말고 "콘텐츠 부족" 섹션으로 보고한다.

## Squint 패스 — 스크립트가 못 잡는 "구성" 슬롭 (LLM 판정, before 스캔 직후)

슬롭은 구성적이다 — CSS를 한 줄씩 읽어서는 못 잡는다. **섹션 크롭을 실제로 보고**(detect.mjs가 남긴 crops/) 5축을 평가해 audit.md에 기록한다. 걸린 섹션은 재설계 대상에 추가된다(개편 모드).

1. **초점 부재** — 모든 요소가 동등하게 경쟁. 처방: 주 목표 하나를 크기·무게·대비·고립로 지배시키고 나머지는 강등
2. **평평한 위계** — 글을 읽지 않으면 주/부/메타를 구분 못 함. 처방: 무게+4단 컬러 램프로 층위(크기만으로 만들지 않는다)
3. **단조 레이아웃** — 카드 크기·간격·밀도가 처음부터 끝까지 동일. 처방: 구역별 밀도 변화, 콘텐츠 성격대로 차등
4. **소심한 색** — 저채도 틴트가 고르게 분산되거나 액센트 하나를 남용. 처방: 의도적 액센트 1색 ~10%, 나머지는 구조적 중립색
5. **보더로 만든 구조** — 여백·톤 대신 선으로 구획. 처방: 디바이더를 간격·서피스 단차로 교체

## 성공 판정 3테스트 (게이트 통과 후 — 게이트는 나쁜 변경을 막고, 이건 좋은 변경인지 판정한다)

카탈로그 전 항목 통과(🔴 0)는 **필요조건이지 충분조건이 아니다** — 토큰 스왑(인디고→틸, Inter→다른 폰트, 이모지 삭제)만으로도 🔴는 전부 지워지지만 잊히는 템플릿은 그대로다. 재감사에서 셋 다 판정해 보고서에 남긴다:

1. **Justified** — 모든 변경이 커밋한 방향에 복무하는가(또 다른 반사가 아니라)
2. **Coherent** — 타입 페어링·팔레트·레이아웃·시그니처가 서로를 강화하는가. "하나의 커밋된 아이디어가 실행됐다"
3. **Not a re-run** — 직전 실행들과 같은 "안전한" 조합을 또 집지 않았는가(direction.md의 반프로필·자기검증 기록이 판정 근거)

개편 모드 등급 A는 퀄리티 바 5/5에 더해 **3테스트 3/3**이 필요하다.

## 재생성 자기검증 (방향·재설계안 확정 직전)

기계 탐지로 못 잡는 제네릭을 잡는 유일한 방법: **"비슷한 브리프를 다시 받아도 이 조합이 또 나오겠는가?"** 그렇다면 그건 선택이 아니라 기본값이다 — 반프로필에 추가하고 재유도한다. 바꾼 것과 이유를 direction.md에 남긴다.

## 병행 탐지기 (선택 — 있으면 쓰고 없으면 건너뛴다)

소스 파일이 있으면 `npx impeccable detect --json <src>` (Apache-2.0 별도 도구, Node 22.18+)를 보조 신호로 병행할 수 있다. 좌표계가 달라(file:line vs 렌더 섹션) 병합하지 않는다 — **역할 분담**: impeccable = 파일·라인 수준 수정 지점, 본 스킬 = 섹션 재설계·게이트 판정. 훅 설치는 하지 않는다(`--no-hooks`). 미설치면 조용히 생략 — 본 스킬 게이트가 SSOT다.

## 개편 모드 퀄리티 바 (탈바꿈의 완료 조건 — 티 0은 필요조건일 뿐)

실측 교훈: 고퀄 레퍼런스도 티는 있다(omneky: 티 21건인데 실자산 밀도로 프리미엄 / plai: 폰트 8단·디스플레이 115px·전 섹션 실스크린샷). **퀄리티는 티 부재가 아니라 아트 디렉션에서 나온다.** 티만 빼고 자산 없는 골격을 남기면 "깨끗하지만 허접한" 결과가 재생산된다.

**이 5항은 완료 조건이자 작업 동력이다** — 개편 모드의 재설계 대상 선정: 구조성 티 섹션 ∪ **아래 미달 섹션**(시각 자산 없음 / 콘텐츠 없는 공백 지배 / 본문·위계 타이포 부실). 티 0인 페이지에서도 이 기준으로 대상을 찾아 진행하고, 아래 5항을 채워야 완료다(보고서에 항별 근거 명시).

1. **디스플레이 모먼트** — 히어로 헤드라인은 본문 기준 4배 이상(방향이 저강도 타이포를 명시 선택한 경우만 예외). 3배대 중간지대가 밋밋함의 주범이다
2. **타입 스케일 6±1단** — 실측 16단은 위계 없음과 같다. 모든 사이즈를 스케일 토큰으로
3. **자산 플랜** — 재설계 착수 전에 섹션별 시각 자산 목록을 확정한다. 우선순위: 실제 제품 화면 캡처(실행 중인 서비스가 있으면 브라우저로 직접 찍는다) > 실사진 > 생성 이미지 > 자산이 안 되면 타이포 중심 구조를 선택. 같은 자산 돌려쓰기는 AS1
4. **색 커밋** — 지배색 1 + 강조 1이 전 섹션을 관통한다. 섹션마다 다른 언어(크림 에디토리얼 + 네이비 글래스 + 옐로 배너 혼재)는 실패
5. **빈 공간은 의도일 때만** — 콘텐츠 없이 남는 영역은 실증(로고·수치·후기·스크린샷)으로 채우거나 섹션을 접는다. "정돈됨"과 "완성됨"을 혼동하지 않는다

**마감 체크리스트 (재설계한 섹션마다 — 마지막 5%가 사람 티를 만든다)**
- 인터랙션 상태 4종(hover/focus/active/disabled) 전부 정의, `transition: all` 금지(속성 명시), active에 미세 프레스 피드백
- 정렬된 숫자엔 tabular numerals, 대형 헤드라인엔 자간 미세 음수(라틴만 — 한글은 KO3)
- 중첩 radius는 동심(안쪽 = 바깥 − 패딩), 새 섹션도 reduced-motion 존중
- 대담함은 시그니처 한 곳에만 — 마지막에 "액세서리 하나를 뺀다"(과잉 장식 1개 제거 후 완료 선언)

## 게이트 기준 (scripts가 집행 — 자가 추정으로 덮지 않는다)

### 섹션 분할 (결정적 캐스케이드)

1. **시맨틱 우선**: `section·header·footer·main` 직계와 role/aria-label 보유 요소가 콘텐츠 높이 70% 이상을 덮으면 채택
2. **래퍼 체인 붕괴**: body부터 "자식 하나가 부모 면적 95% 이상"인 체인을 내려가 콘텐츠 루트를 찾고, 그 직계 자식이 섹션 후보
3. **병합**: 높이 < 뷰포트 15% 후보는 아래 이웃에 병합(마지막은 위로)

### before/after 섹션 매핑

정규화 텍스트 블록 집합의 **자카드 유사도 그리디 매칭**(동률은 문서 순서). n:1(병합) 허용, 매핑은 게이트 산출물에 기록. 각 before-티의 사후조건은 매핑된 after-섹션에서 평가한다.

### 게이트 1 — 티 사후조건

before의 확정 🔴 티와 같은 룰 ID가 매핑된 after-섹션에서 재탐지되면 실패. 목표: 🔴 잔존 0.

### 게이트 2 — 시그니처 린트 ("조정만 했음" 차단, 불만 ③)

적용 범위: **재설계가 요구된 섹션만**(기본 모드 = 구조성 🔴 / 개편 모드 = 구조성 🔴+🟡). **데스크톱 뷰포트에서만** 평가(모바일은 반응형 스택으로 원래 구조가 변함).

섹션 정규화(자식 박스를 섹션 기준 상대 좌표로) 후 **이산 시그니처 4성분**:
1. **행·열 구성**: 자식 박스 y-겹침 행 클러스터링 → 행별 열 수 시퀀스 (카드 3장 한 줄=`[3]`, 목록=`[1,1,1]`)
2. **형제 균일성**: 형제 크기 ε(4px) 동일 여부
3. **정렬 클래스**: 텍스트 블록 중심의 섹션 대비 위치 (centered/left/right)
4. **미디어-텍스트 관계**: 미디어가 텍스트의 above/side/background/none

**4성분 전부 불변 = "조정만 했음" 실패.** 연속 임계치 없음 — ε는 측정 오차 흡수용. 패딩 인플레이션·렌더 무변화 DOM 셔플은 어느 성분도 못 바꾼다.

### 게이트 3 — 텍스트·링크·이미지 불변 (하드)

- **정규화**: 이모지·픽토그램 제거, 공백 접기, NFC. 정규화 후 빈 블록은 자동 통과
- **연접 커버**: after-블록이 before-블록 1개 이상의 연접(순서 보존)과 정확히 일치하면 통과(병합), 역방향 동일(분할). 커버 안 되는 잔여 = 위반
- **삭제 허용 목록**: 순수 서수 블록(`^\d{1,2}$`, `^step ?\d+$` 류)이 CP2 티로 걸린 요소 내부면 삭제 허용 — 보고서 "삭제된 장식 텍스트"에 기재. 그 외 소실은 실패
- **순서 변화**: 통과시키되 경고로 보고
- **링크**: (정규화 앵커텍스트, 해석된 href) 멀티셋 불변 — 삭제는 무조건 위반
- **이미지**: 정보성만 불변 — alt 있는 img, 면적 > 뷰포트 5% 플로우 이미지, 대형(>30vh) 요소의 background-image. 장식(alt=""·aria-hidden·텍스트 없는 인라인 SVG·소형 블롭)은 삭제 가능하되 제거 목록으로 보고

### 측정 조건

- 뷰포트 3종 `1440x900, 768x1024, 390x844` — 분할·시그니처·밀도(DE1·DE2)는 데스크톱 기준(모바일은 반응형 스택·세로 확장으로 오판 원천), 사후조건·텍스트는 뷰포트별
- 테마 토글·`prefers-color-scheme` 감지 시 양 테마 스캔
- ε 상수: 크기 동일 4px / 래퍼 면적 95% / 소형 섹션 15vh / 자카드 동률 tie-break 문서 순서
- **정적 저하 모드**(렌더 불가): 소스 스캔으로 표면성 티 서브셋만 탐지, 게이트 2·밀도·캡처 생략 — 보고서에 "게이트 약함" 명시 (exit와 별개 필드). 저하 모드 감사 항목에는 **[코드확실]/[추정]** 태그를 달아 인식론적 지위를 구분한다 — 픽셀 없이 추론한 것(팔레트 지배색·간격 리듬·위계)을 확실한 것처럼 말하지 않는다
