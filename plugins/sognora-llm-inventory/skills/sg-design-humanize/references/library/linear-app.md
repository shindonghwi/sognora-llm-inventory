# linear.app 분석

장르/단위: 개발자 도구(이슈 트래커) / 랜딩 · 분석일 2026-08-15 · 상태: **구조·인터랙션 미채움** (수치만 실측)

## 수치 (detect.mjs 실측, 1440×900)

- 폰트 11단(max 64px) — 배율 4.3×
- 밀도 중앙값 **30%** — 표본 중 최저. **저밀도가 허접하지 않은 유일 케이스: 다크 베이스 + 절제된 모션 + 제품 화면의 정밀함이 여백을 "의도"로 읽히게 한다**
- 고유 정보성 자산 4(총 20 — 재사용 있음) · 섹션 분할 2개(스크립트가 SPA 구조를 잘게 못 나눔 — 분할 한계 사례)
- 티 프로필: 🔴2 🟡5 — 업계에서 "Linear glow"가 클리셰의 원조가 된 사이트라는 점 유의(M3 티의 기원)

## 구조 / 자산 운용 / 인터랙션

미채움 — scan 수치만 확보. 모션 언어(엔트런스 절제·스크롤 리빌)가 이 사이트의 본체이므로 **probe 없이 인용 금지**.

## 배울 것 (수치 근거 한정)

- 저밀도 30%로도 성립하는 조건: 콘텐츠가 아니라 "정밀 실행"이 여백을 지탱 — 어설픈 팀이 흉내내면 그냥 빈 페이지가 된다(우리 DE1이 그걸 잡는다)

## 버릴 것

- "Linear glow" 복제(M3) — 원조를 베끼는 순간 클리셰
