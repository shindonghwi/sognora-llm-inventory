# 레이아웃 대안 스켈레톤 — 구조성 티의 재설계 재료

> 사용법: 걸린 섹션의 **원본 시그니처와 4성분 중 최소 1개가 다른** 스켈레톤을 고른다(시그니처 린트 통과 조건).
> 여기 있는 것만이 선택지가 아니다 — 방향(direction.md)의 레이아웃 문법이 우선이고, 이 카탈로그는 출발점이다.
> 어느 스켈레톤이든 **콘텐츠가 먼저다**: 실제 텍스트 분량·미디어 유무에 맞는 것을 고른다. 콘텐츠가 안 받쳐주면 rules.md §6 처방(압축/병합/보고)으로 돌아간다.

표기: `[행별 열수 / 균일성 / 정렬 / 미디어]` — 시그니처 4성분.

## 히어로 (슬롭 기본형: 중앙 정렬 + 뱃지 + 큰 여백 `[1,1,1 / - / centered / none]`)

- **비대칭 분할**: 좌측 헤드라인+본문 우세, 우측 실미디어 `[1개 행에 2열 / 비균일 / left / side]`
- **에디토리얼 오프닝**: 신문 1면처럼 대형 타이포가 곧 비주얼, 미디어 없음, 좌측 정렬 + 괘선 `[1,1 / - / left / none]`
- **풀블리드 미디어 + 하단 텍스트 바**: 사진이 배경이 아니라 주인공 `[1,1 / - / left / background→above]`

## 피처 소개 (슬롭 기본형: 아이콘-위 동일 카드 3장 `[3] / 균일 / centered / none]` — LA1)

- **지그재그 교차**: 기능마다 텍스트↔미디어 좌우 교대, 행마다 비대칭 `[2,2,2 / 비균일 / left / side]`
- **에디토리얼 목록**: 카드 없이 번호·괘선로 구분된 세로 흐름, 기능명은 큰 타이포 `[1,1,1 / 비균일 / left / none]`
- **본문 우세 1+N**: 대표 기능 하나를 크게, 나머지는 압축 목록로 `[1,2 또는 2,1 / 비균일 / left / side]`
- **비교 표**: 기능이 속성 비교 성격이면 표가 카드보다 정보 밀도가 높다 `[N행 균일이지만 표는 카드 아님 — LA1 비대상]`

## 단계·프로세스 (슬롭 기본형: 번호 뱃지 카드 반복 — CP2)

- **연결 타임라인**: 괘선 하나로 이어진 세로 단계, 번호는 뱃지가 아니라 타이포 `[1,1,1 / 비균일 / left / none]`
- **산문 전개**: 단계가 3개 이하고 각 단계 설명이 짧으면 번호 없이 이어지는 문단이 낫다 `[1 / - / left / none]`
- **전후 대비**: 프로세스의 본질이 변화라면(도장 전→후) 단계 나열 대신 before/after 병치 `[2 / 비균일 / left / side]`

## 통계·지표 (슬롭 기본형: 숫자 배너 행 — LA2)

- **서사 통합**: 숫자를 문장 안으로 — "3,200곳의 현장에서" `[1 / - / left / none]`
- **근거 연결형**: 숫자 1개 + 그 숫자의 출처·의미 설명을 옆에 `[2 / 비균일 / left / none]`

## 후기·증언 (슬롭 기본형: 동일 카드 3장 캐러셀)

- **단일 인용 대형**: 가장 강한 후기 하나를 크게, 나머지는 한 줄 목록 `[1,1 / 비균일 / left / none]`
- **실사진 결합**: 후기와 그 현장 사진을 병치 `[2 / 비균일 / left / side]`

## CTA (슬롭 기본형: 중앙 정렬 문구 + 버튼, 그라데이션 배경)

- **괘선 마감**: 페이지 끝을 배너가 아니라 각진 마감 섹션으로 — 좌측 문구, 우측 버튼 `[1개 행 2열 / 비균일 / left / none]`
- **본문 연장**: 마지막 섹션 흐름에 버튼만 자연스럽게 — 독립 CTA 섹션 자체를 없애는 병합 `[병합 — 매핑 n:1 기록]`

## 얇은 섹션 (콘텐츠 면적비 미달 — DE1·DE2의 병합 처방)

- **한 줄 압축**: 제목+한 줄짜리 카드 3장 → 구분자로 이어진 한 줄 텍스트 조합 `[3→1행 텍스트 / - / left / none]`
- **이웃 병합**: 위·아래 섹션의 보조 문단으로 흡수 — 텍스트는 전부 보존(연접 커버 게이트가 검증)

## 공통 금지

- 재설계 결과가 또 다른 균일 카드 그리드면 무의미하다 — LA1 사후조건에 걸린다.
- 스켈레톤을 바꾸며 텍스트를 요약·삭제하지 않는다 — 불변 게이트 위반. 정보 구조만 바꾼다.
- 모바일(390px)에서 어차피 세로 스택이 된다는 이유로 데스크톱 구조를 대충 두지 않는다 — 린트는 데스크톱에서 평가한다.
