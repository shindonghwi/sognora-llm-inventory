# sg-design-humanize — CHANGELOG

## 1.2.0 — 2026-08-15 (문서 대정비 — 목적 선언과 정합 복원)

하루 10여 회 증분 패치로 누적된 문서 부채 청산:

- **목적 선언 신설** — 정체성 재정의: "AI 티 제거 스킬"이 아니라 **실측 기준 디자인 개편 시스템**(라이브러리 축적 → 같은 자로 측정 → 기준선까지 개편 → 3대 퇴행을 게이트가 차단). AI 티 제거는 부분집합
- rules.md 재구조화: 카테고리 1~9 번호 정리(6c 등 삽입 사고 해소), 게이트 1→5 순서 복원(4·5가 3 앞에 있던 것), IC4/IC5 순서, 카테고리 일괄 층위 표기를 룰별 표기로 정정(BD1·LA3 등 표면성 룰이 [구조성] 헤더 아래 있던 문제)
- 세션 대화 참조 제거("불만 ①~④"·"스크린샷 2·3·4" — 제3자가 해독 불가한 맥락 오염) → 일반 서술로
- 정합 복원: Squint를 before+after 2회로 명문화, probe.mjs 자기 검수를 절차 8에 편입, 룰 수 37로 통일(README 38 오기 수정), 라이브러리 실측 결론(동시 위계 ≤6단, 호버 transform 금지, duration 수렴, keep-all 전역)을 해당 룰에 반영
- 사고 내러티브를 본문에서 CHANGELOG로 이관(교훈 규칙만 잔류)

## 1.1.0 — 2026-08-15 (레퍼런스 라이브러리 + 인터랙션 프로브)

- **references/library/ 신설 — 스킬의 축적 자산**: 레퍼런스 분석 문서(수치·구조·자산 운용·인터랙션·배울/버릴 것)를 한 번 만들면 영구 보관, 실행은 INDEX에서 장르 맞는 문서를 읽기만(매 실행 분석 금지 — 비용 0). 새 레퍼런스만 1회 분석 후 라이브러리에 편입
- **probe.mjs 신설**: 호버 전후 computed diff(무반응 요소 검출 포함)·스크롤 리빌 패턴·모션 언어(duration/easing/property 분포, transition:all 카운트)·고정 내비·미디어 관찰 — 정지 수치(detect)가 못 보는 "움직임 언어"를 기록
- 시딩: plai(디스플레이 6.4×·자산 24 전부 고유·번호 통합 헤드라인), omneky(자산 59 물량전·한글 로케일 함정 교본), linear(저밀도 30%가 성립하는 조건), toss(한글 타이포 무위반 실증·밀도 51%) — 인터랙션 란은 미채움 표기(1회 probe로 보강 가능)

## 0.2.0 — 2026-08-15 (생태계 리서치 통합 — 지식층 재구축)

기존 스킬 3종(avoid-ai-design·impeccable 59룰·Anthropic frontend-design)과 MIT 자산 2종(interface-design design-deslop, ui-ux-pro-max design-audit)을 정밀 분석해 흡수. 코어(시그니처 린트·불변 게이트·벤치마크)는 생태계에 없는 유일 자산이라 유지, 지식층을 재구축.

- 탐지 +10룰(총 35): BD1 사이드 액센트 보더 · CO5 그라데이션 텍스트 · LA4 중첩 카드 · QF1~6 품질 바닥(가로 오버플로, 정지 시 숨은 콘텐츠, 행폭, 타이포 하한, 탭 타깃, unsized img)
- Squint 패스: 렌더 크롭을 보고 구성 슬롭 5축(초점/위계/단조/색/보더 구조) 판정 — 스크립트 사각 보완
- "슬롭이 아닌 것" 오탐 억제: 동기 있는 대담함·문서화된 이탈·범위 밖·린터 소관 면책, "확신 없으면 결정으로 취급"
- 재생성 자기검증: "비슷한 브리프에 또 나올 조합이면 기본값" — 방향 확정 전 필수
- 방향 7축(+시그니처 단일 집중), 타이포 극단 원칙(무게 100-200/800-900, 점프 3배+), 반프로필에 AI 수렴 룩 세대(크림+세리프+테라코타 등) — 금지가 아니라 "기본값 소비 금지" 프레이밍
- 마감 체크리스트(상태 4종·transition:all 금지·tabular nums·동심 radius·액세서리 하나 빼기)
- impeccable CLI 병행 탐지기 옵션(Apache-2.0 별도 프로세스, file:line 보조 신호 — 게이트 SSOT는 본 스킬)
- 보고 단계에 확정 토큰의 DESIGN.md 고정(이후 이탈 감시 기반)
