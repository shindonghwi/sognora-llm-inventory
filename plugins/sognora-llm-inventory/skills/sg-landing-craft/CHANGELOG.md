## 0.3.0 — 2026-08-16 (클리셰 재발 사고 대응 — 제작 단계 강제 계약)

실전에서 AI 클리셰 산출 발생 — 원인: 안티 클리셰 장치가 전부 후행 검수에 있고 제작 단계에 강제 계약이 없었음. 구조 수정:

- **"문서 없으면 코드 없다"** 철칙 — contract·facts·borrow·DESIGN.md 없이 구현 착수 금지, 금지 목록은 착수 전 필독으로 전진 배치
- **DESIGN.md 토큰 계약 단계 신설(§5)** — 폰트 스케일 전체 목록 + **최소(전체 ≥12px·본문 ≥15px)·최대(디스플레이 = 본문×4~7 캡) 규칙**, 동시 위계 ≤6단, 팔레트·radius·spacing·모션 토큰, 한글 3원칙. 계약 밖 값 사용 금지
- **최종 시각 검증을 독립 필수 단계(§10)로 분리** — 전 뷰포트 캡처를 눈으로 보고 Squint+퀄리티 바 항별 판정, 생략 금지
- **평가 루프 신설(§11)** — 대상 사용자 페르소나 평가자(새 컨텍스트)가 5문항 평가, "무엇을 파는 페이지인가"를 틀리면 무조건 🔴 반영 후 재평가. 평가 없이 완료 선언 금지, A등급 조건에 포함
