## 자산 운용

**캐릭터 라이브러리 하나를 3개 스케일로 돌린다.** `/front-static/agents/*.png` 한 세트(book · globe · files-v2 · checkmark · light_bulb · apple · mailbox · rock · sign)가
- 72px → 히어로 아바타 파일 (`pile_*.webp`)
- 52~56px → 히어로 장식 위성
- 40px → 컴팩트 카드 아이콘

으로 재등장한다. 새 그림을 그리는 게 아니라 **같은 배우를 다른 배역에 다시 세운다.**

**위성은 2겹 합성이다.** 손그림 캐릭터 PNG(52px) 위에 **실제 서드파티 앱 로고 SVG**(39~46px)가 겹친다 — `tasks/github.svg` `gmail.svg` `hubspot.svg` `slack.svg` `checkWhite.svg` `chartWhite.svg`. 캐릭터=에이전트, 로고=그 에이전트가 지금 쓰는 도구. 스크롤하면 로고가 갈아끼워진다(스크롤 0에서 GitHub였던 자리가 1100에서 HubSpot). **일러스트가 장식이 아니라 문장을 말한다.**

**제품 스크린샷은 씬으로 조립한다.** 벤토 하나에 실제 UI 크롭 2~4장을 겹친다 — 예: 554×554 베이스 + 554×136 핀 카드 + 452×56 챗 입력. `bento_bentoInner`의 `overflow:hidden` + `radius:12px`가 넘치는 부분을 카드 실루엣으로 잘라내 "화면 밖으로 이어지는 제품"의 인상을 만든다.

**고객 로고는 mask-image로 단색화한다.** SVG를 `<img>`로 넣지 않고 `mask-image: url(...)` + `background-color: rgba(0,0,0,.898)`. 브랜드 원본 파일을 편집하지 않고도 전부 같은 잉크로 통일되고, hover 배경색까지 CSS로 붙는다.

**세리프는 3곳뿐이다.** Lyon Text가 후기 인용문 3개에만, 그것도 18px로. 790곳이 NotionInter인 페이지에서 세리프 3곳 — 희소성 자체가 "여긴 사람 말"이라는 신호가 된다.

**히어로는 영상이다.** 정지 스크린샷이 아니라 1920×1200 mp4(autoplay·loop·muted) + 사용자용 Pause 버튼.

### 호버 표 (probe 14표본 + 직접 계측)

| 대상 | 변화 | 판정 |
|---|---|---|
| 주 버튼 | bg `#0075DE` → `#005BAB` | 유일한 색 변화 |
| 내비 링크 | bg `transparent` → `rgba(0,0,0,.05)` | |
| 로고월 항목 | bg `transparent` → `#F6F5F4` | |
| 벤토 카드 | **변화 없음** (자식 40개까지 확인) | 무반응 |
| 컴팩트 카드 | **변화 없음** | 무반응 |
| 후기 카드 | **변화 없음** | 무반응 |
| 로고 · Pause · 카드 내부 링크 | **변화 없음** | 무반응 10/14 |

**카드에 호버 상태가 아예 없다.** lift도 그림자 증가도 테두리 강조도 없다. 호버 어포던스는 버튼·링크·로고 같은 **원자 단위 컨트롤에만** 주고, 큰 면은 정적으로 둔다. probe가 "무반응 10건"으로 잡은 게 방치가 아니라 설계다.

### 리빌

`hiddenAtRest 1 / revealedAfterScroll 0` — **스크롤 진입 페이드업이 없다.** 요소는 처음부터 그 자리에 있다.

### 모션 언어

- transition duration 2종뿐: `0.2s`(81곳) · `0.15s`(10곳). easing은 `cubic-bezier(0.42,0,1,1)`(ease-in) 81곳 + `ease` 10곳
- transition property: `background-color`(82) · `color`(13) · `outline-color`(5) · `box-shadow`(3) · `border-color`(1) · `all`(1). **transform 트랜지션 0곳** — 움직이는 요소가 없다
- 팝오버: `popoverFadeIn` + `popoverSlideUp` **0.15s** `cubic-bezier(0,0,0.58,1)`
- 마퀴: `60s linear infinite`
- 캐릭터 위성: 진입 `0.6s ease-in-out` + **스크롤 구동** `1s linear` (`Agent_agentMarkScroll` / `agentTaskScroll` / `agentScroll`)
- 알림 카운터: `steps(7)` · `steps(10)` — 스크롤에 맞춰 숫자가 **이산적으로 딸깍딸깍** 올라간다

### 로고월 sticky 밴드

```css
position: sticky;
bottom: -48px;   /* 밴드 높이 96px의 정확히 절반 */
```

스크롤 0~400: 뷰포트 하단에 물려 **2행 중 1행만** 보인다. 800부터 풀려 캡션(y1349) 아래 자기 자리(y1385)에 정착하고 2행 전부 드러난다. 히어로를 읽는 내내 신뢰 신호를 접힘선에 붙여두다가, 다 읽으면 놓아주고 전문(全文)을 보여주는 교대다.

### 회전 단어

`Scale → Think → Ship → Create → Build → Jam` 6단어 순환. 단어마다 알약 배경색과 좌측 점 색이 함께 바뀌고, 알약 폭이 단어 길이를 따라 238~319px로 늘었다 줄었다 한다. 이건 임의의 파스텔이 아니라 **Notion 제품 안의 select 속성 태그 색 언어를 96px 디스플레이 스케일로 끌어올린 것**이다. 랜딩이 제품의 시각 문법을 인용한다.

### 메가메뉴

## 배울 것

1. **장식용 그리드 트랙을 이름 붙여 따로 판다.** `[content-start] 122px 24px [center-start]` — 콘텐츠 컬럼 바깥에 122px 레일을 정식 트랙으로 선언해두고 거기에만 일러스트를 놓는다. `position:absolute`로 눈대중 배치하는 것과 결과가 다르다: 반응형에서 장식이 본문을 침범할 수 없고, 레이아웃 계약서에 "여긴 장식 자리"가 명시된다.

2. **트래킹을 크기의 함수로 만든다.** 96px에서 -4.6px(-0.048em), 54px에서 -1.875px(-0.035em), 22px에서 -0.25px, 16px 아래는 normal. 큰 글자를 그냥 키우기만 하면 자간이 벌어져 성기게 보인다 — 이 램프 하나가 디스플레이 타이포의 완성도 절반이다.

3. **중립 서피스를 3개로 끝낸다.** `#FFFFFF` / `#F9F9F8` / `#F6F5F4`. 4633px 페이지 전체가 이 셋으로 굴러간다. 화이트 베이스에서 위계는 배경색 개수가 아니라 **여백·타이포 크기·자산 밀도**로 만든다.

4. **그림자 알파 상한을 0.04로 못 박고, 면 분리는 헤어라인에 맡긴다.** 4~6스톱 물리 램프를 쓰되 어느 스톱도 0.04를 안 넘는다. 카드 테두리는 그림자가 아니라 `1px solid rgba(0,0,0,.1)`. "떠 있음"을 표현할 때만 그림자를 쓰고 "구분"에는 안 쓴다.

5. **그라데이션은 가독성 스크림에만 쓴다.** 전 페이지 3개, 전부 `transparent 35% → rgba(0,0,0,.55)`. 장식 그라데이션 0개. 스캐너가 CO2(🟡)로 잡았지만 이게 정확히 그라데이션을 **써도 되는** 유일한 용법이다.

6. **세리프를 인용문 3곳에만 쓴다.** 790:3 비율. 보조 서체를 넓게 깔면 그냥 서체가 두 개인 사이트가 되고, 한 역할에만 묶으면 그 역할의 목소리가 된다.

7. **일러스트 자산 한 세트를 세 스케일로 재사용한다.** 72/52/40px. 자산 개수를 늘리는 대신 같은 캐릭터를 다른 배역에 다시 세워 페이지 전체가 한 세계로 읽히게 만든다.

8. **일러스트에 정보를 실어라.** 손그림 캐릭터 + 실제 앱 로고(GitHub·Slack·Gmail·HubSpot) 2겹 합성. 캐릭터가 귀여워서 있는 게 아니라 "에이전트가 당신 도구를 쓴다"는 문장을 그림으로 말한다. 스크롤에 따라 로고가 갈리며 문장이 계속 이어진다.

9. **`overflow:hidden` + `radius`로 제품 스크린샷 씬을 만든다.** 실제 UI 크롭 2~4장을 카드보다 크게 겹쳐 놓고 카드 실루엣으로 자른다. 화면이 카드 밖으로 이어지는 인상이 생기고, 납작한 스크린샷 한 장보다 깊이가 산다.

10. **호버는 원자 컨트롤에만 준다.** 버튼·링크·로고에는 0.2s 배경색 전환, 카드 면에는 아무것도 없음. 카드 lift는 안 해도 되는 일이었다는 실증 사례. transform 트랜지션이 페이지에 0곳이다.

11. **스크롤 리빌 없이도 성립한다.** `revealedAfterScroll 0`. 페이드업 없이도 4633px가 지루하지 않은 이유는 자산 자체가 움직이기 때문(히어로 mp4, 60s 마퀴, 스크롤 구동 캐릭터). **엔트런스 애니메이션과 살아있는 콘텐츠는 대체재**다.

12. **로고월을 `sticky; bottom: -48px`로 반쪽만 물린다.** 접힘선에 신뢰 신호를 붙여두다가 히어로를 다 읽으면 놓아주고 전문을 보여준다. 오프셋이 밴드 높이의 정확히 절반.

13. **랜딩에서 제품의 시각 문법을 인용한다.** 회전 단어 알약 6색은 Notion 제품 안 select 태그 팔레트다. 랜딩용으로 새 색을 만들지 않고 제품 색을 96px로 확대했다 — 랜딩과 제품이 같은 물건이라는 가장 싼 증명.

14. **고객 로고는 `mask-image` + `background-color`로 단색화한다.** 원본 SVG를 편집하지 않고 잉크색 통일 + hover 배경까지 CSS로 처리. 로고 17개를 관리하는 가장 실무적인 방법.

15. **폰트 램프를 UI/디스플레이 두 사다리로 쪼갠다.** 12·14·16·18·20·22 / 42·54·72·96. 22와 42 사이의 빈칸이 "여기부터는 다른 목적"이라는 선언이다. 10단이 난립처럼 보여도 두 램프로 읽으면 6+4다.
