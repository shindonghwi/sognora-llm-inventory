# sg-demand-mine — CHANGELOG

## 0.3.0 — 2026-08-18 (A급 정의 오류 교정 — 3회 실행이 전부 과금 분쟁으로 수렴한 원인)

실전 3회에서 A급이 29→90→178건으로 늘었는데 카드는 계속 0이었다. 원인은 채널이 아니라 **A급 정의**였다: "돈 언급"을 지불 증거로 삼으니 앱스토어 리뷰에서 **돈을 뜯겼다고 느끼는 사람**만 길어 올렸다. 그들은 더 낼 의사가 없고, 벤더는 고칠 의지가 없으며, 제3자가 들어갈 자리가 없다.

- **증거 클래스 재정의**: A급 = **지불 의사**(현재 유료 사용자의 기능 갭 + 공개 가격표) / **D급 = 분쟁**(해지·환불·과금 오류·가격 인상) — 카드 근거 불가, 집계만. `signals.mjs`가 어휘로 자동 분류(검증 7/7), `cards.mjs`가 D급 근거 카드를 탈락
- **분쟁 > 지불 의사면 수집 로그가 경고** — 채널·키워드를 바꾸라는 신호
- **A급 주력 채널을 공개 가격표 마켓으로 이동**(Shopify·WordPress) — 앱스토어 리뷰는 분쟁 편향
- **signals.mjs에도 정합성 검사 이식** — 사람이 준 키워드도 검사(실전: `msp psa`→트레이딩 카드 감정 앱, `connectwise`→원격제어 앱)

## 0.2.0 — 2026-08-17 (첫 실전 실행 피드백 반영 — 생존자 0으로 끝난 런에서 결함 7건 수확)

- **시드-앱 정합성 검사(가장 큰 구멍)**: 앱스토어가 질의와 무관한 앱을 물어와 기회 점수가 조용히 가짜가 되던 문제(pap smear→Paper.io 2 게임, airbnb and vrbo→Expedia). 장르·토큰 검사로 제외하고 **측정된 앱 이름을 결과 표에 노출**(seeds.md만 봐도 오염이 보이게), 제외 사유도 보고
- **B2B 채널 신설**: Shopify 앱스토어·WordPress 플러그인 — 앱스토어가 구조적으로 못 잡는 업무용 3자 앱 생태계(실측 확인)
- **panel.mjs 신설**: 킬 패널을 산문에서 파일 계약으로. 6개 기준 심문·**경쟁 제품 실물 확인(이름·가격)**·역구성 판정 기재를 검증하고, 미완이거나 "역구성 불일치인데 survive" 모순이면 P5 차단
- **cards.mjs 강화**: 인용 앞부분 잘라내기 검출(문제 재포장), `currentSpend.evidenceClass`(quoted/public-pricing/estimated — 추정은 관찰 목록 격리), A급 12개월 신선도, ledger 중복을 토큰 유사도로(문장만 바꾼 재제안 차단)
- 수집 로그에 언어·지역 분포 기재(rules §9 미구현분)

## 0.1.0 — 2026-08-17 (신규)

"매번 이상한 아이디어, 어디 꽂힌 것, 시대에 안 맞는 것"을 세 장치로 차단하는 수요 채굴 스킬. 하브루타 1라운드 + 전 계기 실행 검증을 거쳐 신설.

- **계기 3종(전부 실측 검증)**: `seeds.mjs`(구글·네이버 자동완성 문형 확장 → 문제 구절 → 앱스토어 유량·불만·방치·신규진입·HN 추세로 랭킹), `signals.mjs`(앱스토어 리뷰·Reddit·HN·GitHub 증거 수집, 차단 채널 정직 기록), `cards.mjs`(카드 린터 — 인용 코퍼스 verbatim 대조·A급 하한·지불자 특정·why-now 날짜·first-dollar·유통·클리셰 입증·ledger 중복)
- **설계 원칙**: 시드를 사람이 고르지 않는다(고르는 순간 그가 아이디어를 낸 것) / 누적이 아니라 유량으로 잰다 / A급은 돈이 오간 흔적만 / 카드 0개도 정직한 결과(할당량 금지) / A급 채널 전멸 시 카드 생성 금지
- **채널 실측(2026-08)**: 열림 — 구글·네이버 자동완성, 앱스토어 검색·리뷰 RSS, HN Algolia, GitHub·StackExchange API, Reddit. 차단 — G2·Capterra·Trustpilot·ProductHunt·Fiverr·Upwork(우회 금지, 로그 기록). 정책 제외 — 외주·구인 마켓
- sg-biz-validate와의 절단선 명문화(발굴 vs 검증, 심층 경쟁분석·TAM·PRD 금지)
