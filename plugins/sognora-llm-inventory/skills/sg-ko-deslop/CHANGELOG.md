# sg-ko-deslop — CHANGELOG

## 0.3.1 — 2026-11-03

- 사용자가 채널 댓글을 여러 줄 해설에서 시청자가 단 것 같은 한 줄 반응으로 바꿨다(「왜케 ai같지」 「간결하잖아」). 규칙도 맞췄다.
- C6 구독·좋아요·알림 부탁을 더했다(「좋아요, 구걸하지말자」).
- C5 기준을 30자에서 60자로 올렸다(「30자 안팎, 길어도 두 줄」). 해설 댓글만 본다는 0.3.0의 범위 제한은 뺐다.
- 구독 부탁 줄 끝 이모지 예외를 없앴다. 댓글의 이모지는 모두 G-C5다.

## 0.3.0 — 2026-11-02

- 장르 `댓글`: 유튜브 고정·해설 댓글, 답글, 채널 설명. 경로에 「댓글」 「채널 설명」이 있으면 이 장르로 짐작한다.
- 규칙 C1~C5(소개 문장, 머리말, 날짜·회의 나열, 안내문 톤, 한 줄이 김). 사용자가 쇼츠 채널의 해설 댓글과 채널 설명 후보를 보고 짚었다. C5는 해설 댓글과 채널 설명에 적용하고, 답글·한 줄 고정 댓글에 걸리면 오탐으로 거른다.
- 반존대는 잡지 않는다. 업무 글 규칙(P3~P9)을 끄고, 대구는 ⚪로 낮췄다. 구독·좋아요·알림 부탁 줄 끝의 이모지 하나는 둔다. 따옴표 안 말은 문체 규칙에서 건너뛴다.
- 게이트: `댓글`은 빠지기만 한 숫자를 ⚠️로 알리고 넘어간다. 바뀌거나 새로 생긴 숫자는 그대로 실패다.
- 기존 7개 장르의 판정은 그대로다.

## 0.2.0 — 2026-11-02

- P9 개조식 자리의 「~합니다」: 표지·기능 카드·목록·표 칸·제목 밑 한 줄을 「~검사합니다」 「되돌립니다」 같은 문장으로 쓰는 것. 사용자가 제안서 표지를 보고 짚었다.
- P1에 「눌러 볼 수 있는」, P4에 「~해 두었습니다」(「운행 기록을 넣어 두었습니다」)를 더했다.
- 오탐 「합니다체 종결 반복」을 본문 문단과 대본으로 좁혔다. 제안서의 개조식 자리는 오탐이 아니다.
- 눈으로 볼 것에 「홍보 페이지 같은 표지」를 더했다.

## 0.1.0 — 2026-11-02

- 장르 7개: 제안서·발표·대본·영상·화면·보고·글. 장르마다 켜는 규칙과 심각도가 다르다(`scan.py` `RULES`).
